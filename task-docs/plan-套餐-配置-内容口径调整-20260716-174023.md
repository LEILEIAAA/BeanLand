# plan-套餐-配置-内容口径调整

## 目标

套餐页内容口径调整：五月天主题拼豆局只走活动；包场套餐改名并调价为 1999。

## 范围

- `miniprogram/data/seed.js`
- `scripts/cloudbase-seed-export/packages.json`
- `scripts/cloudbase-seed-export/activities.json`
- `miniprogram/pages/home/index.js`（移除 mayday-theme 映射）
- `miniprogram/pages/activities/index.js`（包场文案同步）
- 云库 `packages` / `activities` 对应文档

## 现状

- 套餐含 `mayday-theme`（五月天主题拼豆局 ¥99）与 `birthday-party`（生日会 / 包场 ¥1299）
- 活动已有 `mayday`、`birthday`（同名，生日仍为 ¥1299）
- 套餐页优先读云库 `packages`，空/失败才回退 seed

## 改动方案

1. 从套餐列表删除 `mayday-theme`
2. 包场套餐改名为「生日会 / 团建 / 包场」，价格改为 1999
3. 活动 `birthday` 同步改名与价格；`mayday` 活动保留
4. 清理首页 `PACKAGE_AUDIENCE_LABEL['mayday-theme']`；活动页 blurb 同步
5. 刷云库：删除 packages/`mayday-theme`，更新 packages/`birthday-party` 与 activities/`birthday`

## 风险

- 云库若未同步，线上仍显示旧套餐（页面优先读库）
- 历史订单若引用 `mayday-theme` 包 ID，仅影响新购，不改历史单

## 验证思路

- Node 断言 seed：无 mayday-theme；birthday-party / birthday 名为新文案且 price=1999
- 尝试 tcb 更新云库并核对
