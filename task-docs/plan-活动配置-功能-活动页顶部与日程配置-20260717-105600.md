# 活动页顶部与日程可配置化

## 目标
让店主在后台「活动配置」里编辑活动页（`pages/activities/index`）顶部文案与「开业首周日程」，摆脱写死内容。

## 范围
- 后台「活动配置」列表页顶部新增「页面头部/日程」配置入口 → 新页面编辑。
- 顶部三字段：标题(大标题)、副标题(顶部小标，现 Opening Week 行)、内容(描述句)。
- 日程：日程标题 + 若干日程项；每项手填「日期标签」，其余(标题/备注/状态)自动取所选活动。
- 配置存 `store/main` 文档 `activitiesPage` 字段，与首页轮播 `heroPhotos` 同源。

## 现状
- 顶部 hero 与日程均写死在 `pages/activities/index.wxml` / `.js`（`OPENING_WEEK`）。
- 参照：首页轮播 = `getHomeBanners`(读) + `adminSaveHomeBanners`(写) + `utils/homeBanners.js`(归一化) + `pages/admin/home-banners`。

## 改动方案
### 数据结构（store/main.activitiesPage）
```
activitiesPage: {
  hero: { title, subtitle, content },
  schedule: { title, items: [ { day, activityId } ] }
}
```

### 新增文件
- `miniprogram/utils/activityPageConfig.js`：`normalizeActivityPageConfig` / `buildScheduleRows` / 常量与默认值。
- `cloudfunctions/getActivityPageConfig/{index.js,package.json}` + `activityPageConfig.js`（读，公开）。
- `cloudfunctions/adminSaveActivityPageConfig/{index.js,package.json}` + `activityPageConfig.js`（写，管理员）。
- `miniprogram/pages/admin/activities/page-config.{js,json,wxml,wxss}`。

### 修改文件
- `miniprogram/utils/api.js`：`getActivityPageConfig` / `adminSaveActivityPageConfig`。
- `miniprogram/pages/activities/index.{js,wxml}`：读配置渲染 hero + 日程（join 活动）。
- `miniprogram/pages/admin/activities/index.{js,wxml}`：顶部入口按钮 + `goPageConfig`。
- `miniprogram/app.json`：注册 page-config。
