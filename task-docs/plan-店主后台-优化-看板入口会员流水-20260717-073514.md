# 计划：店主看板入口重排 + 会员管理 + 储值流水

## 目标

- 看板去掉底部统计，按经营入口重排并改名
- 新增「会员管理」「储值流水」页面与云函数，数据读云端真库

## 范围

- `miniprogram/pages/admin/dashboard/*`：入口重排、去统计
- `miniprogram/pages/admin/members/*`：会员列表/详情（含等级）
- `miniprogram/pages/admin/transactions/*`：储值流水（分类筛选 + 金额汇总）
- `cloudfunctions/adminListMembers`、`adminListMemberTransactions`
- `miniprogram/utils/api.js`、`app.json`、`cloudbaserc.json`
- 可测纯逻辑：`adminDashboardMenu`、`adminMemberDisplay`、`transactionStats`

## 非范围

- 不做会员套餐/优惠券资产明细
- 不改会员端消费明细页
- 不恢复代充入口（已有 `admin/recharge` 保持不动）

## 改动方案

### 看板入口顺序

1. 座位管理 / 订单管理
2. 预约管理 / 活动管理
3. 套餐核销 / 优惠券管理
4. 会员管理 / 储值流水

### 会员管理

- 搜索手机号/昵称；无关键词时列最近会员
- 列表/详情：昵称、手机号、等级（普通会员/VIP/SVIP）、余额
- 云函数 `adminListMembers`

### 储值流水

- 读 `member_transactions`，分类：全部 / 充值 / 消费 / 退款
- 顶部汇总：收入合计、支出合计、净额、笔数
- 云函数 `adminListMemberTransactions`

## 风险

- 云函数需部署后真机才有数；本地测以单元测试 + 代码契约为准
- `members` 大表无关键词全量需 limit，开业期可接受
