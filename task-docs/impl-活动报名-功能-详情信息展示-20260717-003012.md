# impl-活动报名-功能-详情信息展示

## 实际改动

- seed / activities.json 为每场活动补充 `scheduleText`、`timeText`、`audience`、`content`、`includes`、`notice`
- 新增 `utils/activityDetail.js` 组装详情行
- 报名页增加「活动详情」区块

## 验证结果

```text
node --test tests/activityDetail.test.js
node scripts/check-activities-page.js
```

## 残留风险

云库旧活动文档缺详情字段时，报名页会与 seed 合并后展示；完整落库需重新 import activities。
