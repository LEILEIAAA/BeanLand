# plan-店主后台-优化-会员选中去重

## 目标

去掉套餐核销 / 优惠券 / 转账代充三页中与会员结果行重复的「当前选中」展示。

## 范围

- `package-redeem` / `coupons` / `recharge` 的 WXML（及必要 WXSS）
- 不含 `timer`；不含业务逻辑改动

## 现状

三页均在会员列表下方再渲染「当前选中」，与上方 `.member-row.active` 信息重复。

## 改动方案

删除「当前选中」UI；保留 JS `selectedId`/`selectedLabel`；套餐核销 active 态补圆角。

## 风险

低。仅展示层；跳转开台仍读 `selectedLabel`。

## 验证思路

grep 确认三页无「当前选中」；确认 package-redeem 仍写入/使用 `selectedLabel`。

`done`
