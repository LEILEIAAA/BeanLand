# 计划：注册页取消自动返回会员

**执行状态：** done

## 目标

资料完善时进入注册页不再自动 `navigateBack`；仅用户点击底部「完成注册并返回」才返回会员页。

## 范围

- `miniprogram/pages/member/register/index.js`
- `miniprogram/pages/member/register/index.wxml`

## 改动方案

1. 删除 `bootstrap` 中 `registrationComplete` 时调用 `finishAndBack` 的逻辑。
2. 删除 `maybeFinish` 及各保存路径上的调用；保存后只 toast + refreshFlags。
3. 文案改为提示用户点底部按钮返回。

## 验证

- 静态确认无自动返回调用路径。
- 跑既有 `memberProfile` / `wxProfile` 相关测试。
