# plan-活动管理-修复-封面选图隐私失败

**执行状态：** `done`

## 目标

修复店主后台「新建/编辑活动」封面：点击后立刻 toast「上传失败」、相册不弹出的问题。

## 根因判断

用户确认现象 **1**：一点就失败、相册未开 → 失败点在 `wx.chooseMedia`，不是 `cloud.uploadFile`。

在 `__usePrivacyCheck__: true` 下，常见原因为：
- 隐私弹窗监听未生效 / 未先走 `requirePrivacyAuthorize`，接口直接 fail
- 公众平台隐私指引未声明「选中的照片或视频」，接口直接 fail（无弹窗）
- 错误被统一吞成「上传失败」，无法区分

## 范围

- 新增可测错误文案映射：`mediaPickError`
- 活动编辑页：先隐私授权再选图；toast 展示可行动原因
- 隐私弹窗：文案补照片用途；`detached` 注销监听避免脏监听
- 同步首页轮播 / 我的拼豆选图错误提示（同源问题）

## 非目标

- 不改云存储路径与保存字段
- 不代替老板在公众平台勾选隐私声明（若报「未声明」需人工勾 A4）

## 改动方案

1. `miniprogram/utils/mediaPickError.js` + 单测：cancel / privacy / permission / 默认
2. `privacy-popup`：文案含相册；`offNeedPrivacyAuthorization` 在 detached
3. `activities/edit.js`：`requirePrivacyAuthorize` → `chooseMedia` → upload；错误走映射
4. 封面热区改 `button`（去掉默认 button 样式），保证手势与隐私链路稳定
5. `home-banners` / `works` 错误提示同源

## 验证思路

- `node --test tests/mediaPickError.test.js` 全绿
- 静态走查 edit 页选图流程
- 真机/开发者工具：点封面应先出隐私弹窗（若未同意）或相册；若后台未声明则 toast 明确提示「隐私指引未声明照片」
