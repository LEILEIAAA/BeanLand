# 实现：会员等级视觉样式

## 实际改动

- `tierStyleClass`：将 `member` / `vip` / `svip` 映射为 CSS 类
- 会员页资产卡与徽章绑定 `tierClass`
- VIP：暖琥珀底 + 金徽章；SVIP：更深橙琥珀光晕 + 橙金徽章与充值钮

## 关键决策

- 只改会员页资产卡皮肤，不改升级阈值、不扩后台列表
- 色系沿用充值页暖黄/橙品牌色，避免紫色皮肤
