# 活动报名去掉待支付

## 目标
活动报名仅区分「已购买 / 未购买」；已购买出现在「我的活动报名」，未购买不展示任何记录。

## 方案
- 微信支付下单写入 `activity_pay_orders`（status=paying），不写入 `activity_registrations`
- 支付回调 `payActivityNotify` 成功后才创建 `activity_registrations`（status=paid）
- 用户列表仅返回 paid / refund_pending
- 移除 pending_pay 状态及相关 UI 逻辑
- 微信付款成功后轮询我的报名列表确认到账
