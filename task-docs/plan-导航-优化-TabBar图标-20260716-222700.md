# plan-导航-优化-TabBar图标

## 目标

原生 tabBar 为「首页 / 活动 / 套餐 / 会员」补开源风格线条 icon（未选中 / 选中双态）；完成后评估是否仍需自定义 tabBar 调高度。

## 范围

- `miniprogram/assets/tab/` 新增 8 张 PNG（Lucide 风格）
- `miniprogram/app.json` 配置 `iconPath` / `selectedIconPath`
- `scripts/check-tabbar-nav.js` 校验 icon 路径与文件存在

## 非范围（阶段 A）

- 自定义 `custom-tab-bar` / 高度可调（阶段 B，视 A 效果再定）

## 方案

- 图标源：Lucide（ISC），导出 81×81 PNG，透明底
- 未选中色 `#8B8B8B`，选中色 `#111827`（与现有 tabBar 色一致）
- 映射：home / calendar-days / package / circle-user

## 风险

- 微信开发者工具需重新编译才能看到 tab 图标变化

## 验证思路

- `node scripts/check-tabbar-nav.js` 通过
- 开发者工具目视四 tab 有 icon 且选中态变深
