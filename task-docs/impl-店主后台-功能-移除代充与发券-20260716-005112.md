**时间戳：** 20260716-005112  
**Nova run：** 20260716-005045

## 实际改动

1. **看板**：移除「转账代充录入」按钮与 `goRecharge`；核销入口文案改为「优惠券核销 / 发放」。
2. **发券纯函数**：`buildIssueCouponPayload`（校验 memberId/openid/name、面额≥0、有效天数为正整数，默认 30 天；写入 unused + available）。
3. **云函数**：新增 `adminIssueCoupon`（admins 校验 → 读会员 → 组 payload → `user_coupons.add`）。
4. **店主优惠券页**：选中会员后展示发放表单（券名/面额/范围/有效天数），确认后调用发券并刷新未使用列表；核销逻辑保留。
5. **注册**：`api.adminIssueCoupon`、`cloudbaserc.json` 增加函数项；`coupons.js` 同步至相关云函数目录。

## 关键决策

- 只去入口，不删 `pages/admin/recharge` / `adminRecharge`（按「移除入口」默认假设）。
- 不做券模板表；店主手填即发。
- 前端用同一纯函数做提交前本地校验，与云侧规则一致。
