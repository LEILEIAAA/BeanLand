# 计划：店主看板入口分组两列宫格

## 目标

店主看板入口按业务分组，两列宫格呈现，按使用频率排序，便于快速识别与跳转。

## 范围

- `miniprogram/utils/adminDashboardMenu.js`：扁平菜单改为 `sections` 结构
- `miniprogram/pages/admin/dashboard/*`：分组标题 + 两列宫格 UI
- `tests/adminDashboardMenu.test.js`：覆盖分组顺序与入口

## 非范围

- 不改各子页功能与路由
- 不新增入口、不删入口

## 改动方案

分组（自上而下）：

1. **现场运营**（置顶加重）：座位管理、订单管理
2. **预约活动**：预约管理、活动管理
3. **营销核销**：套餐核销、优惠券管理
4. **会员资金**（沉底）：会员管理、储值流水

呈现：分组标题 + 两列宫格；现场运营格子视觉略重。

## 风险

- 小程序端样式需单独 wxss，避免依赖不存在的全局 grid 类

## 验证思路

- `node --test tests/adminDashboardMenu.test.js`
- 看板结构肉眼确认（分组标题 + 两列）
