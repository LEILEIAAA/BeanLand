# 实现：充值页选档确认与自由额度

## 实际改动

- 新增 `resolveCustomRecharge`：最低 1 元；向下取最近档赠送
- `createRechargeOrder` 支持 `customAmount`（与 `planId` 二选一）；自定义单 `planId=custom`
- 充值页：点选档位/自由额度 + 底栏确认 + 实付/赠送/到账预览
- 同步 `rechargeOrder.js` 至 common / create / notify / admin 四份副本

## 关键决策

- 自由额度赠送与前端预览共用同一纯函数，避免前后端规则漂移
- 自定义订单只快照金额与赠金，`planId` 固定为 `custom`

## 残留风险

- 需重新上传部署 `createRechargeOrder` 云函数后，真机自由额度下单才生效
- 若库中仍保留调试档（0.02），自由额度 ≥0.02 会命中其赠送（约定上线前改档）
