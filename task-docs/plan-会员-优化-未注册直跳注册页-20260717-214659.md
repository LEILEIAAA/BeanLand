# 未注册直跳注册页

## 目标
未注册用户点击指定功能入口时，去掉弹窗确认，直接进入 `/pages/member/register/index`。

## 范围
1. 会员页所有可点按钮
2. 套餐页「立即购买」
3. 活动报名入口（列表 join + 报名确认）
4. 首页「预约开拼」

## 判定
统一使用 `isRegistrationComplete`（头像 + 昵称 + 手机号）。

## 改动方案
- 新增 `miniprogram/utils/memberRegisterGate.js`：`REGISTER_URL`、`needsMemberRegister`
- 各入口去掉 `showModal`，未注册直接 `navigateTo`/`redirectTo`
- 预约页 `ensureMemberGate` 同步改为直跳（防御其他入口）

## 验证
- `node --test tests/memberRegisterGate.test.js`
- 静态检查各入口无 `请先注册`/`去注册` 弹窗文案

## 执行状态
`done`
