# impl-活动报名-修复-人数不刷新

## 实际改动

- 新增 `listActivities` 云函数，从云库返回真实 `registeredCount`
- `api.getActivities` 优先调用 `listActivities`，失败再回退直读/seed
- 报名/取消成功回传 `registeredCount` / `capacity` / `activityStatus`
- 报名页 `applySeatSnapshot` 即时刷新名额展示，再 bootstrap

## 关键决策

- 根因是前端直读被 seed 掩盖，不是云侧未加人数
- 用云函数读目录数据，绕过客户端集合权限/空读问题

## 残留风险

- 微信开发者工具需刷新/重新编译小程序端才能吃到新 `api.getActivities`
- 若 `listActivities` 未部署，仍会回退 seed（人数仍可能为 0）
