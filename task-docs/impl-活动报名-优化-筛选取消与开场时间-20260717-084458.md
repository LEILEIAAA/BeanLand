# impl-活动报名-优化-筛选取消与开场时间

## 实际改动

1. **管理页筛选**：全部 / 已报名 / 已取消；移除「待退款」。`cancelled` 组包含 `cancelled` + `refunded` + `refund_pending`。
2. **退款失败兜底**：`refund_pending` 文案改为「退款失败」，按钮「重试退款」；看板角标仍统计该状态。
3. **用户取消**：成功提示「已取消」；微信退款失败提示联系店主。取消云函数本就自动退微信款，未改状态机主路径。
4. **startAt**：线上三场已是正确开场时间（7/18 14:00、7/21 14:00、7/24 19:00），patch `nModified=0`，无需改规则。

## 关键决策

- 「已取消」筛把退款失败一并纳入，避免再单独开「待退款」tab。
- 取消档位（24h / 30%）保持不变。
