# impl-活动报名-功能-取消手续费与管理页样式

## 实际改动

1. **取消规则**：`resolveCancelPolicy` / `calcCancelRefund` / `assertUserCancelAllowed` / `buildCancelConfirmContent` / `resolveWechatRefundFeeFen`
   - `>24h` 全额；`≤24h` 扣实付 30%；已开始或无 `startAt` 不可取消
2. **云函数**：`cancelActivityRegistration` 校验档位并按 `refundFeeFen` 退；`adminConfirmActivityRefund` 同口径；`listMyActivityRegistrations` 附带 `startAt`
3. **前端**：报名页 / 我的报名取消确认展示退款与手续费；管理页对齐预约管理（hero + 卡片 + 报名时间）
4. **数据**：活动 seed / export 补 `startAt`（开业三场），notice 写明取消规则
