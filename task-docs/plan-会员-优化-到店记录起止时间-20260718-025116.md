# 会员到店记录显示起止时间

**执行状态：** `done`

## 目标

会员「到店记录」已结束会话展示为 `开始时间 - 结束时间`，一眼可读；进行中仍只显示开始时间。

## 范围

- `miniprogram/utils/seatSessionHistory.js`：`mapMemberSessionRow` 输出 `timeRangeLabel` / `endedLabel`
- `miniprogram/pages/member/seat-sessions/index.wxml`：用时间范围替换原先仅开始时间
- `tests/seatSessionHistory.test.js`：覆盖已结束与进行中

## 方案

对齐现有 `formatChinaDateTime`；已结束：`{started} - {ended}`；进行中或无 `endedAt`：仅开始时间。时长行保留不变。
