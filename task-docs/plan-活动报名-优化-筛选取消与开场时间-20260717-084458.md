# plan-活动报名-优化-筛选取消与开场时间

## 目标

按确认方案 A2 + B1：

1. 店主「活动报名管理」筛选改为：全部 / 已报名 / 已取消；移除「待退款」。
2. 用户取消后自动退款（云函数已具备）；退款失败仍保留重试；「已取消」筛包含 cancelled / refunded / refund_pending。
