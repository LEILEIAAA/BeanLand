# plan-座位管理-修复-座位板下发座位列表

## 目标

座位管理页在接口异常/客户端读库失败时仍能看到座位图与会话态。

## 执行状态

`done`

## 现状与根因

1. `adminListSeatBoard` 云端可正常返回 `ok:true`（含 sessions / inUse / reservationsBySeatId），但**不含 seats**。
2. 座位管理页 `refreshBoard` 另调客户端 `api.getSeats()`（直读云库 `seats`）；`ALLOW_SEED_FALLBACK=false` 时读失败 → 空座位图 + Toast「接口异常」。
3. 次因：`project.private.config.json` 的 `libVersion` 覆盖为 `3.16.2`，与项目约定 `3.5.5` 冲突，存在云能力不稳定风险。

## 改动方案

| 层 | 改动 |
|----|------|
| 云函数 | `adminListSeatBoard` 服务端加载 seats（集合优先，失败则 tables 生成）并随板返回 |
| 前端 | `refreshBoard` 优先使用 `board.seats`；loading 用 try/finally 防卡死 |
| 工具 | `resolveSeatsForBoard` / `normalizeSeatRow` 纯函数 + 单测 |
| 配置 | `project.private.config.json` libVersion → `3.5.5` |
