# plan-会员注册-修复-防重复跳转

## 目标

未注册拦截跳转注册页时，连续快速点击只打开一层注册页。

## 范围

- `miniprogram/utils/memberRegisterGate.js`：新增 `openMemberRegister`
- 各入口改走统一方法：会员、首页、活动、套餐、活动报名、充值、预约（redirect）
- `tests/memberRegisterGate.test.js`

## 现状

各处直接 `wx.navigateTo({ url: REGISTER_URL })`，无进行中锁，双击叠两层。

## 改动方案

1. `openMemberRegister`：pending 锁 + 栈上已有注册页则跳过；支持 `replace: true` 走 `redirectTo`
2. 所有注册跳转入口替换为该方法

## 风险

- 锁过长可能挡住合法再次进入（返回后再点）→ complete 后短延迟解锁，并用栈检查兜底
- 预约页现用 `redirectTo`，需保留 replace 语义

## 验证思路

- `node --test tests/memberRegisterGate.test.js`
- 用例：连续两次只触发一次 navigate；栈上已有注册页不再跳
