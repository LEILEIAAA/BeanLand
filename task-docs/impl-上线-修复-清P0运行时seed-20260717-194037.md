# 实现：清 P0 运行时 seed 露出

## 实际改动
1. 新增 `miniprogram/utils/storeResolve.js`：`resolveStorePayload` 仅在 `allowSeedFallback` 时回退 seed。
2. `api.getStore`：改用上述解析；云空时抛 `store not found`，不再无条件 `return seed.store`。
3. P0 页面全部去掉 `require(.../data/seed)`：
   - 路线 / 首页：读 `api.getStore`（及首页轮播、主推云列表）
   - 套餐 / 活动 / 充值：默认空列表，只用云返回
   - 预约：时段空则 toast，不塞 seed
   - 活动报名：只认云活动
   - 后台轮播：云空则空列表

## 关键决策
- 零兜底：云失败/空数组展示空态，不用本地假数据顶上。
- 套餐页本地 `DEFAULT_PROMO`（写死 8 折）一并改为 `EMPTY_PROMO`，避免云挂时仍显示开业折扣条。
- `seed.js` / 导出脚本 / 受开关保护的会员页死代码保留。

## 残留风险
- 云库未导入 `store` / 套餐 / 活动 / 时段时，对应页为空（需确认云数据齐全）。
- 首页首屏可能短暂空白，等云返回。
- 会员页仍有 `ALLOW_SEED_FALLBACK` 死代码路径（当前关，属 P1）。
