# impl · 预约 · 超时未到店 15 分钟

**对应 plan：** `plan-预约-功能-超时未到店15分钟-20260716-175300.md`  
**规格：** `docs/superpowers/specs/2026-07-16-appointment-no-show-hold-design.md`  
**Nova run：** `20260716-175247`

## 实际改动

1. **纯函数** `appointmentRegistration.js`：新增 `no_show` / `HOLD_MINUTES` / `resolveNoShowDeadline` / `shouldMarkNoShow` / `buildNoShowFields`；`pending` 标签改为「待商家确认」。
2. **结算** `settleNoShow.js`：列表入口将超时 `confirmed` 更新为 `no_show` 并删除对应 `reserved` 占用。
3. **云函数**：`listMyAppointments` / `adminListAppointments` / `adminListSeatBoard` 返回前结算；相关函数同步 `appointmentRegistration.js`。
4. **座位汇总**：`seatSession` 忽略 `no_show` /「未到店」。
5. **文案**：我的预约说明、取消弹窗、预约成功页兜底、店主预约管理副文案。

## 关键决策

- 触发用打开列表结算，无定时器。
- 超时状态用 `no_show`，与用户 `cancelled` 区分。
- 截止点取首个时段开始时间 + 15 分钟（+08:00）。
