# plan-导航-优化-TabBar压矮彩标

## 目标

自定义底栏再压矮；图标从灰线稿改为 Bean Land 软彩圆角色块。

## 范围

- `scripts/generate-tab-icons.js`：软彩 tile（橙/粉/黄/蓝）双态 PNG
- `miniprogram/assets/tab/*.png`：重新生成 8 张
- `miniprogram/custom-tab-bar/index.wxss`：高度约 88rpx
- `miniprogram/app.wxss`：`.tab-page` 底部留白同步收紧
- `scripts/check-tabbar-nav.js`：校验新高度与留白

## 非范围

- tab 顺序 / 文案 / 路由不变
- 页面内容区视觉改版

## 方案

- 未选中：淡彩圆角底 + 白色 glyph；选中：饱和彩底 + 白色 glyph
- 映射：首页豆粒橙 / 活动星光粉 / 套餐礼物黄 / 会员心形蓝
- 底栏：`88rpx + safe-area`；图标 `40rpx`；字 `18rpx`；`.tab-page` 留白 `108rpx`

## 风险

- 微信开发者工具需重新编译才见 icon 变化
- 过矮可能导致拇指误触边缘；88rpx 为可点下限附近

## 验证思路

- `node scripts/check-tabbar-nav.js` 通过
- 目视四 tab 为软彩色块、底栏明显变矮
