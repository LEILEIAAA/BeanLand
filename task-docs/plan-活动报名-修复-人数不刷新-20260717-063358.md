# plan-活动报名-修复-人数不刷新

## 目标

报名/取消成功后，活动列表与报名页展示的「已报 x/y」与云库 `activities.registeredCount` 一致。

## 范围

- 新增云函数 `listActivities`，客户端经云函数读活动
- `api.getActivities` 优先走云函数
- `createActivityRegistration` / `cancelActivityRegistration` 回传座位快照
- 报名页用回传字段即时刷新 `seatLabel`（再 bootstrap）

## 现状

- 云函数报名已 `bumpActivitySeat`；云库 mayday 已为 1
- 前端直读 `activities` + seed 回退，界面长期显示 seed 的 `0/xx`

## 改动方案

| 层 | 改动 |
|----|------|
| 纯逻辑 | `activityList.js`：`normalizeActivityRow` / `mapActivityList` |
| 云函数 | 新建 `listActivities`；create/cancel 返回 `registeredCount` 等 |
| 小程序 API | `getActivities` 优先 `listActivities` |
| 报名页 | 成功后应用座位快照再 bootstrap |

## 风险

- 需部署 `listActivities` 后前端才稳定；未部署时仍回退直读/seed
- 多副本 `activityRegistration.js` 需同步回传字段（若放共享 util）

## 验证思路

- 单测：normalize / seat snapshot 映射
- 本地 `node --test` 相关用例
- 部署后：报名 → 列表与详情人数 +1
