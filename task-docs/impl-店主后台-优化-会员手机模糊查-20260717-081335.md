- 抽出 `memberSearch`：`buildPhoneSearchPattern`（无 `^` 锚点的包含匹配）+ `phoneMatchesKeyword`
- `adminFindMember` / `adminListMembers` 数字关键词改用包含匹配，尾号/中间片段可命中
