# 会员设置整行热区

## 目标
设置页列表行整行可点（含右侧头像/文案/箭头），不再只有中间空白区生效。

## 范围
- `miniprogram/pages/member/settings/index.wxss`（必要时微调 wxml）

## 现状 / 根因
`.set-row-hit` 虽 `inset: 0` 覆盖整行，但右侧 `set-row-value`（头像、文案、chevron）叠在上层并吃掉点击，透明按钮收不到事件。

## 改动方案
1. `.set-row-hit` 提高 `z-index`，保证覆盖层在最上。
2. `.set-row-label` / `.set-row-value` 设 `pointer-events: none`，点击穿透到按钮或行 `bindtap`。
3. 昵称 `input` 单独 `pointer-events: auto`，保持可编辑。

## 验证
- 静态：wxss/wxml 含 z-index + pointer-events 约定，语法可 parse。
- 真机/开发者工具：点头像、右侧手机号、›、协议行右侧均能触发。
