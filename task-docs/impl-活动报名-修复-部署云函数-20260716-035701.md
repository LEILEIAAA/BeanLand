# impl-活动报名-修复-部署云函数

## 问题

小程序活动报名页 `cloud.callFunction` 报 `-501000 FunctionName parameter could not be found`。

## 根因

`createActivityRegistration` 等 6 个云函数本地已实现并登记在 `cloudbaserc.json`，但未部署到环境 `cloudbase-d8gzrj9d3f09c5171`。

## 实际改动

部署以下云函数（`tcb fn deploy <name> -e cloudbase-d8gzrj9d3f09c5171 --force`）：

- createActivityRegistration
- payActivityNotify
- cancelActivityRegistration
- listMyActivityRegistrations
- adminListActivityRegistrations
- adminConfirmActivityRefund

无业务代码变更。

## 验证结果

- `tcb fn list`：6 个函数均为 Deployment completed
- `tcb fn invoke`：均可触发，不再出现 FUNCTION_NOT_FOUND
- `listMyActivityRegistrations` 无登录态返回 `NO_OPENID`（预期）
- 集合 `activity_registrations` 已存在（查询返回空列表）

## 残留风险

- 需在真机/开发者工具重新进入活动报名页做一次完整报名冒烟（余额/微信）
- 微信退款仍为店主人工确认
