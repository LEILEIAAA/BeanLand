## 实际改动

### UI

### 优惠券核查与修复
- **原问题**：套餐页 / 购买云函数读 `member.coupons`；真源已是 `user_coupons`（`listMyCoupons`），导致几乎永远「暂无可用优惠券」
- **可用性逻辑**：原本只认 `status === 'available'`，云券是 `unused` + `available` 布尔
- **修复**：
  - `packagePurchase` 增加 `normalizePurchaseCoupon` / `resolveCouponOffAmount`，识别 `unused`、折算折扣券、排除小时券
  - 套餐页打开弹层时调用 `listMyCoupons({ tab: 'unused' })`
  - `purchasePackage` / `createPackageOrder` / `payPackageNotify` 改为读写 `user_coupons`（核销 / hold / release）

## 关键决策

- 小时券不参与套餐价抵扣（权益类型不匹配）
- 折扣券按 `benefitValue` 折（如 8 折 = 实付 80%）
- 不再读写 `members.coupons`（零兜底，切真源）

- 需重新上传云函数：`purchasePackage`、`createPackageOrder`、`payPackageNotify` 后线上才生效
