# impl-导航-优化-TabBar图标

## 实际改动

- 用 Lucide 风格 SVG 栅格化为 81×81 透明 PNG；第二轮改为更小字形（scale 0.62）+ 细线（1.5）+ 品牌向符号
- 映射：首页 bean、活动 sparkles、套餐 gift、会员 heart
- 未选中 `#A1A1AA`，选中 `#18181B`；字形 scale 0.52、线宽 1.25
- `app.json` 配置双态 icon；`borderStyle` 改为 `white` 弱化顶部分割线
- `check-tabbar-nav.js` 校验 icon 文件存在 + `borderStyle === white`

## 关键决策

- 原生 tabBar 无法彻底关闭顶线，只能 `borderStyle: white` 贴近白底；若仍可见需上自定义 tabBar
- 用内边距缩小字形而非改微信固定展示槽，视觉更精致

## 变更文件

- `miniprogram/assets/tab/*.png`（8 张）
- `miniprogram/app.json`
- `scripts/check-tabbar-nav.js`
- `scripts/generate-tab-icons.js`

## 验证结果

```
node scripts/check-tabbar-nav.js
→ OK tabBar= 首页 | 活动 | 套餐 | 会员；borderStyle white
```

## 残留风险

- 部分机型上白边线仍可能隐约可见
- 需开发者工具重新编译目视确认
