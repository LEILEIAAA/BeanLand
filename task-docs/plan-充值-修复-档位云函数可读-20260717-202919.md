# 计划：充值档位云函数可读

## 目标
体验版充值页能读到 `recharge_plans`（集合 ACL=PRIVATE，客户端直读失败）。

## 范围
- 新增 `listRechargePlans` 云函数（服务端读库）
- `api.getRechargePlans` 优先走云函数（对齐 `listPackages`）
- 纯逻辑 `normalizeRechargePlan` / `mapRechargePlans` 可测

## 现状
- 云库已有 r100/r300/r500/r1000
- 集合 `AclTag=PRIVATE`，客户端 `readCollection('recharge_plans')` 读不到
- `ALLOW_SEED_FALLBACK=false`，体验版空白

## 改动方案
1. `miniprogram/utils/rechargePlans.js` + 云函数副本：归一化 id/金额，按 `rechargeAmount` 升序
2. `cloudfunctions/listRechargePlans`：返回 `{ ok, list }`
3. `api.js`：`callFunction('listRechargePlans')` 优先
4. `cloudbaserc.json` 注册并部署
5. `tests/seedRuntimeLeak.test.js` 约束优先云函数

## 风险
- 未部署云函数时仍空白（需部署）
- 客户端直读回退在 PRIVATE 下仍无效（可接受，与 packages 一致）

## 验证思路

- 部署后体验版充值页出现 4 档
