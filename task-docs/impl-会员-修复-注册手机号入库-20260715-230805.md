## 实际改动

1. `normalizePhone` 剥离中国区号 `86`/`+86`，微信带区号号码可过校验
2. 新增 `pickWechatPhone`：优先 `purePhoneNumber`，再回退规范化 `phoneNumber`
3. 云函数 `getPhoneNumber` / `ensureMember` / `createRechargeOrder` 对齐同一规则
4. 注册页微信授权与手填：仅 `ensureMember` 成功且云端 `member.phone` 有效才算完善；去掉「云失败本地冒充完成」

## 关键决策

- 云端 `members.phone` 为唯一完善依据；本地 `beanMemberPhone` 仅作成功后的缓存与再次打开时回写线索
- 不在会员页用本地号绕过充值校验
