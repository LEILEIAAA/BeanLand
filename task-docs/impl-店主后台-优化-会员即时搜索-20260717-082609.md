# 实现：店主后台会员即时搜索（防抖+最短位）

## 实际改动

- 新增 `adminMemberSearch`：`shouldRemoteSearchMember`（纯数字 ≥4 位；昵称非空即可）、防抖常量 300ms
- 会员管理 / 充值 / 发券 / 套餐核销：输入防抖远程搜；「查找」仍可立即触发
- 开台：保留即时搜，补上最短 4 位数字门槛
- 即时搜未命中不弹 toast（避免边输边烦）；点「查找」仍提示
