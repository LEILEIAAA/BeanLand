## 目标

会员页资产卡与等级徽章随 `member` / `vip` / `svip` 切换不同视觉样式，一眼能看出等级差异。

## 范围

- 会员页顶部资产卡（背景光晕、边框气质）+ 等级徽章色
- 不改升级阈值逻辑；不改后台列表样式

## 方案

- `memberTier.js` 新增 `tierStyleClass(tier)` → `tier-member` | `tier-vip` | `tier-svip`
- 会员页 `asset-card` / `tier-badge` 绑定该类
- 样式：普通保持现有石色；VIP 暖琥珀金；SVIP 更深橙琥珀 + 更强光晕（沿用充值页品牌暖色，不用紫）
