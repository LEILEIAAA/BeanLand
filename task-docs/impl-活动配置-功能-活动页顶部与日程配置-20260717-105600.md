# 实现记录：活动页顶部与日程可配置化

## 实际改动
后台「活动配置」新增「页面头部/日程配置」入口，店主可编辑活动页顶部文案与日程；日程项从已有活动中选择。

### 新增
- `miniprogram/utils/activityPageConfig.js`：`normalizeActivityPageConfig`（归一化+默认值）、`buildScheduleRows`（日程项 join 活动）、常量。
- `cloudfunctions/getActivityPageConfig/`：读 `store/main.activitiesPage`，公开。
- `cloudfunctions/adminSaveActivityPageConfig/`：管理员写入 `store/main.activitiesPage`。
- `miniprogram/pages/admin/activities/page-config.{js,json,wxml,wxss}`：配置页。
- `tests/activityPageConfig.test.js`：6 用例。

### 修改
- `miniprogram/utils/api.js`：`getActivityPageConfig` / `adminSaveActivityPageConfig`。
- `miniprogram/pages/activities/index.{js,wxml}`：hero 三字段 + 日程改读配置渲染；删除写死的 `OPENING_WEEK`；日程为空时隐藏该区块。
- `miniprogram/pages/admin/activities/index.{js,wxml}`：顶部入口 + `goPageConfig`。
- `miniprogram/app.json`：注册 `pages/admin/activities/page-config`。

## 关键决策
- 字段映射（按老板选择）：标题→大标题 `act-title`，副标题→顶部小标 `act-kicker`（原 Opening Week 行），内容→描述 `act-sub`。
- 日程项 = `{ day, activityId }`；标题/简介/状态运行时从所选活动取（name / blurb 或 scheduleText / 状态中文）。
- 配置与首页轮播同源存 `store/main`，读写云函数各自内置归一化，未配置回落默认文案（显示默认，非兼容兜底）。
- 引用活动被删 → `buildScheduleRows` 过滤该项；后台展示「（活动已删除）」提示。
