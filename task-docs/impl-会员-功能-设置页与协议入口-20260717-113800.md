# 实现：会员设置页与用户协议/隐私政策入口

## 实际改动
### 新增页面
- `pages/member/settings/index`（设置页）：列表行样式，含头像、昵称、会员号（只读）、手机号四行资料项，及「用户协议」「隐私政策」两行跳转。
  - 头像：透明 `chooseAvatar` 按钮覆盖整行，选后云同步。
  - 昵称：透明 `type="nickname"` input 覆盖整行，blur 后云同步。
  - 手机号：透明 `getPhoneNumber` 按钮覆盖整行，换号后 `ensureMember` 入库。
  - 会员号：取 `member._id/id` 去符号后末 8 位大写展示，缺失占位 `—`。
- `pages/legal/agreement/index`（用户协议）、`pages/legal/privacy/index`（隐私政策）：内容由 data 数组驱动，分节 + 列表项，含手机号收集说明。

### 修改
- `app.json`：pages 数组新增上述 3 个页面路径。
- `pages/member/index`：头像资料卡点击由 `goRegister` 改为 `goSettings`，新增 `goSettings` 跳转设置页。

## 关键决策
- 复用注册页的头像/昵称/手机号云同步逻辑（`ensureMember` / `fetchWechatPhone` / `wxProfile`）。
- 注册页 `pages/member/register` 保留，仍作充值/套餐/活动/预约下单的"完善资料"前置门；设置页为日常资料管理入口，两者功能一致不冲突。
- 数据模型无性别/生日/邮箱字段，按零兜底原则未臆造。
- 退款规则页本轮未做，待用户确认。

- ReadLints 无错误，4 个新文件落盘，入口路径一致。

## 追加实现（20260717-1200 隐私授权与客服入口）
### 改动
- `app.json`：新增 `"__usePrivacyCheck__": true`，开启微信隐私合规校验。
- 新增组件 `components/privacy-popup/index.{js,json,wxml,wxss}`：
  - `attached` 内注册 `wx.onNeedPrivacyAuthorization`，被隐私接口触发时弹窗。
  - 「同意并继续」按钮 `open-type="agreePrivacyAuthorization"`，回调中 `resolve({ event:'agree', buttonId:'pp-agree-btn' })`；「拒绝」`resolve({ event:'disagree' })`。
  - 「《隐私保护指引》」链接调 `wx.openPrivacyContract` 打开后台配置的指引。
- 弹窗组件接入所有会调用隐私接口的页面：`member/settings`、`member/register`（getPhoneNumber/chooseAvatar）、`member/works`、`admin/home-banners`、`admin/activities/edit`（chooseMedia），各页 json 加 usingComponents、wxml 加 `<privacy-popup />` 根节点。
- `member/settings`「关于」分组新增「联系客服」行，`open-type="contact"`。

### 验证
- ReadLints（组件 js + 8 个 json/wxml 关键文件）无错误。
- 未跑：真机隐私授权弹窗与客服会话（需真机 + 后台提交隐私指引后生效）。建议后台《隐私保护指引》提交通过后，真机验证首次授权手机号时弹窗出现、同意后可继续。

### 依赖的后台操作（用户执行）
- 微信公众平台提交《隐私保护指引》，声明：微信头像昵称、手机号（本次不含照片/位置）。
- 客服需在公众平台配置客服人员或客服消息，`open-type="contact"` 才有会话可进。
