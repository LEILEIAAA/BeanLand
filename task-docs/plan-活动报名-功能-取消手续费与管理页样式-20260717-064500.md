# plan-活动报名-功能-取消手续费与管理页样式

## 目标

1. 用户取消报名按活动 `startAt` 分档：`>24h` 全额退；`≤24h` 且未开始扣实付 30%；已开始或无 `startAt` 不可取消。
2. 店主「活动报名管理」页视觉对齐预约管理（hero + 卡片 + 报名时间）。

## 范围

- `miniprogram/utils/activityRegistration.js` + 云函数副本同步
- `cancelActivityRegistration` / `adminConfirmActivityRefund` 按 `refundFeeFen` 退
- 用户取消确认文案（报名页 / 我的报名）
- `listMyActivityRegistrations` 附带 `startAt`
- activities seed / export 补 `startAt`
- `admin/activity-registrations` wxml/wxss/js 样式

## 非范围

- 手续费后台可配
- 活动档期 join 展示（管理页只加报名时间）
