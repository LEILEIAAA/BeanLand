# plan-套餐-功能-双价与开业特惠

## 目标

按新口径改造套餐页与购买计价：周末/工作日双价、三人同行一人免单、开业七天全场 8 折。

## 默认假设

1. 旧套餐全部替换（含包场），包场仅留活动
2. 三人同行一人免单 = 按单人档付 2 人价（周末 139.8 / 工作日 99.8）
3. 无限体验 = 当日不限时
4. 开业 8 折：`store.packagePromo.active=true` 时全场套餐生效；计价前后端同一套逻辑
5. 结算价按「中国时区当天是否周末」自动选工作日/周末价，再乘 8 折

## 范围

- seed / packages.json / store.json
- `packagePurchase.js` + 云函数副本与下单入口
- 套餐页 UI、首页推荐映射
- 云库 packages / store 同步
