## 残留风险

## 修复补充（2026-07-17）

- **根因**：`.map(mapMemberSessionRow)` 把数组下标 `0` 当成 `now`，耗时恒为 0
- **修复**：`resolveClock` 仅接受毫秒时间戳；列表改为 `.map((row) => mapMemberSessionRow(row))`
- **副标题**：固定简介改为「开台座位、用时与消费记录」（不随进行中动态替换）；角标仍为时钟 +「已进行 Xx分钟」
