# impl-活动报名-优化-已生效筛选

## 实际改动

1. 活动管理筛选项：全部 / 已报名 / **已生效** / 已取消。
2. 「已生效」定义：`status=paid` 且关联活动 `startAt>0` 且当前时间已到开场（票务制，无新核销态）。
3. 云函数查 paid 后关联 `activities` 回填 `activityStartAt` / `isEffective`；筛 effective 时只返回已生效行；卡片标签展示「已生效」。
4. 「已报名」仍为全部 paid（含已生效子集）。

## 关键决策

- 不引入 `used`/`redeemed` 状态，避免与套餐核销混淆。
- 无 `startAt` 的活动不进「已生效」，与取消策略「无开场时间不可取消」一致。
