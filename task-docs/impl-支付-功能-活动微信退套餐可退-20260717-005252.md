# impl：活动微信自动退款 + 套餐未核销可退

## 实际改动

1. **活动微信退款自动化**
   - `cancelActivityRegistration`：微信取消后调 `cloudPay.refund`；成功 → `refunded`；失败保留 `refund_pending` + `refundFailReason`
   - `adminConfirmActivityRefund`：改为重试调用微信退款 API
   - 领域新增 `markActivityRefundFailed`；`applyAdminConfirmRefund` 清空失败原因

2. **套餐会员主动退（未过期）**
   - 状态：`user_refunding` / `user_refunded` / `user_refund_pending`
   - 新云函数 `refundPackageOrder`；余额退余额，微信走云支付退款
   - `listMyPackageOrders` 退款 Tab 含主动退记录
   - 「我的套餐」未使用可申请退；挂起可重试；过期后不可主动退（仍走自动过期退）

## 关键决策

- 活动取消领域仍先落 `refund_pending`（名额先释放），再调退款 API
- 套餐主动退与过期退状态分开，便于列表区分文案
- 不做店主代退套餐、手续费、充值退款
