# 计划：店主后台会员即时搜索（防抖+最短位）

## 目标

按建议统一会员查找体验：开台保持即时搜；其余入口改为输入即搜；统一防抖 300ms、数字关键词至少 4 位再打云函数。

## 范围

- 新增可测工具：`miniprogram/utils/adminMemberSearch.js`
- 改造：开台 timer、会员管理、充值、发券、套餐核销
- 保留「查找」按钮作立即触发（仍受最短位约束）

## 非范围

- 不改云函数查询逻辑
- 不改额度配额配置

## 规则

| 关键词 | 是否远程搜 |
|--------|------------|
| 空 | 否（会员列表回最近；其他清空结果） |
| 纯数字且 &lt; 4 位 | 否 |
| 纯数字 ≥ 4 位 / 非数字昵称 | 是（防抖 300ms） |
