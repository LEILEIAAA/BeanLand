# 计划：店主看板预约活动待处理角标

## 目标

预约管理、活动管理入口显示待处理数量；红底白字圆角标，绝对定位不占布局。

## 范围

- `miniprogram/utils/adminDashboardMenu.js`：角标文案与挂载
- `miniprogram/pages/admin/dashboard/*`：拉取待处理数并展示
- `tests/adminDashboardMenu.test.js`

## 非范围

- 不改云函数；复用现有 `status` 筛选接口
- 不加其它入口角标

## 改动方案

- 预约待处理：`adminListAppointments({ status: 'pending' })` 条数
- 活动待处理：`adminListActivityRegistrations({ status: 'refund_pending' })` 条数
- `badge`：0 不展示；1–99 原样；>99 显示 `99+`
- 样式：红圆白字，`position: absolute` 贴宫格右上角

## 验证思路

- 看板真机/模拟器看角标定位与数字
