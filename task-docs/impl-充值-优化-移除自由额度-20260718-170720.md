# 实现：充值页移除自由额度

## 实际改动

- 充值页仅保留固定档位选择 + 底栏确认；删除「其他 / 自由额度」入口与金额输入
- `createRechargeOrder` 仅接受 `planId`，拒绝自定义金额下单
- 删除 `resolveCustomRecharge` / `CUSTOM_*` / `normalizeYuan`，同步四份云函数副本
- 单测改为断言自定义充值 API 不再导出

## 关键决策

- 零兜底：不保留 `customAmount` 兼容路径；旧客户端若仍传自定义金额将收到 `planId required`
