# impl-会员注册-修复-拦截偶发失效

## 实际改动

1. **加固 `openMemberRegister`**：`fail` / 未成功时立即清锁，避免跳转失败后短窗口内无法重试。
2. **前端入口**：首页预约、活动报名、我的预约去预约在跳转失败时 toast；预约页未 `memberReady` 不渲染提交表单；`onShow` 从注册页返回时复检；充值改完整三项注册判定；套餐 `confirmPay` 再次 `guardPhone`。
3. **后端**：新增 `memberRegistration.assertMemberRegistered`，接入 `createAppointment` / `createActivityRegistration` / `purchasePackage` / `createPackageOrder` / `createRechargeOrder`，空壳或缺项一律 `REGISTER_REQUIRED` / `NOT_MEMBER`。

## 关键决策

- 云端与小程序同口径：头像已选 + 非默认昵称 + 合法手机号。
- 充值不再「仅有手机号即可」，与预约/支付一致。
- 预约页 `onLoad` 门禁后跳过紧随的一次 `onShow` 复检，避免连点 toast。
