# impl-座位管理-修复-座位板下发座位列表

## 实际改动

1. **云函数 `adminListSeatBoard`**：服务端加载座位列表（`seats` 集合优先，空则用 `tables` + `buildSeatsFromTables`），响应新增 `seats` 字段。
2. **前端座位管理页**：`refreshBoard` 优先使用 `board.seats`；仅当云函数未带 seats 时才回退客户端 `getSeats`；`loading` 用 `try/finally` 防卡死；错误用 modal 展示完整文案。
3. **纯函数** `miniprogram/utils/seatBoard.js`：`normalizeSeatRow` / `resolveSeatsForBoard`。
4. **配置**：`project.private.config.json` 的 `libVersion` 从 `3.16.2` 改回 `3.5.5`（与 `cloud.js` 约定一致，避免云能力注入异常）。

## 关键决策

- 座位图数据改由店主云函数下发，不再依赖客户端直读 `seats` 的 ACL。
- 不硬编码 FALLBACK_TABLES；仅读云库 seats/tables。
