# 首页轮播重进死循环 — 实现记录

## 实际改动
- 拆分 `heroIndex`（圆点/文案展示）与 `swiperCurrent`（仅圆点跳转写 `current`）。
- `bindchange` 只更新展示态，不再回写 `current`，切断 circular 双绑死循环。
- `onShow` 重载 banners 时保留当前索引，不再强制 `heroIndex: 0`。
- 圆点点击在 `swiperCurrent` 已等于目标时先 nudge 再跳转，避免 autoplay 后同值无法驱动。

## 关键决策
- 根因是微信小程序经典坑：`current` 双向绑定 + `circular`，不是 interval/autoplay 本身。
- 用纯函数集中 patch 逻辑，便于单测断言「change 不含 swiperCurrent」。
