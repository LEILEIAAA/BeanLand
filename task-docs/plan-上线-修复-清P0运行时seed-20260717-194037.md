# 计划：清 P0 运行时 seed 露出

## 目标
去掉提审/真机仍可能展示的本地 `seed.js` 数据：路线、首页门店、列表页默认、预约时段、`getStore` 无条件回退等。

## 范围
- 改：`miniprogram/utils/api.js`（`getStore`）
- 改：`pages/route`、`pages/home`、`pages/packages`、`pages/activities`、`pages/activities/register`、`pages/recharge`、`pages/appointment`、`pages/admin/home-banners`
- 测：纯函数 + 页面源码静态断言（禁止 P0 页 `require(...seed)`）
- 不删：`miniprogram/data/seed.js`、导出脚本、测试用 seed、受 `ALLOW_SEED_FALLBACK` 保护的会员页死代码

## 方案
1. 抽出 `resolveStorePayload`：云 doc / 集合有数据才返回；仅 `allowSeedFallback` 时才用 seed；否则 `null`
2. `getStore`：解析结果为 `null` 时抛错（不再无条件 `return seed.store`）
3. 路线/首页：`api.getStore()` + `getHomeBanners`；初始空态，失败 toast/空展示
4. 套餐/活动/充值/首页主推：默认 `[]`，只用云返回（含空数组）
5. 预约：去掉 `timeSlots` 空时硬塞 seed
6. 活动报名：只认云活动，去掉 seed merge
7. 后台轮播：云空则空列表，不回退 seed

## 风险
- 云库 `store`/`packages` 等未导入时页面变空——符合零兜底，需确认云库有数据
- 首页首屏可能短暂空态，等云返回

## 验证
- `node --test tests/seedRuntimeLeak.test.js tests/storeResolve.test.js`
- 相关既有测试不红
- 静态：P0 页面无 `data/seed` require
