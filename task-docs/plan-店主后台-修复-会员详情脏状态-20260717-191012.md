# 计划：会员详情脏状态修复

## 目标

切换不同会员进入详情时展示对应用户；无会员 / 无流水时清空上一次数据，不残留。

## 范围

- `miniprogram/utils/adminMemberDetail.js`（新建：按 id 精确取会员 + 详情重置态）
- `miniprogram/pages/admin/members/detail.js`（同步 id、加载前置空、请求序号）
- `miniprogram/pages/admin/members/index.js`（跳转 `encodeURIComponent`）
- `tests/adminMemberDetail.test.js`

## 非范围

- 云函数契约变更
- 详情页 UI 改版

## 改动方案

1. 抽取 `pickMemberFromList`：必须按 `_id`/`id` 精确匹配，禁止 `list[0]` 兜底
2. 抽取 `buildMemberDetailReset`：进入详情即 `member=null`、`transactions=[]`
3. 详情页：`onLoad` 同步写入 `_memberId` 并置空；`loadDetail` 用序号忽略过期响应
4. 列表跳转对 id 做 URL 编码

## 风险
