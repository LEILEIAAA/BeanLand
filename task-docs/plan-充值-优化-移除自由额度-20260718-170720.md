# 计划：充值页移除自由额度

## 执行状态

`done`

## 目标

充值页仅保留固定推荐档位；移除「自由额度」入口、自定义金额下单能力及相关逻辑。

## 范围

- 前端：`pages/recharge` 去掉自由额度 UI 与 custom 选中/预览/下单分支
- 云函数：`createRechargeOrder` 仅接受 `planId`
- 共享逻辑：删除 `resolveCustomRecharge` / `CUSTOM_*`，并同步四份 `rechargeOrder.js` 副本
- 测试：删除自由额度单测，改为断言不再导出该 API

## 非范围

- 不改固定档位数据与会员等级说明
- 不改后台代充流程

## 改动方案

1. 测试先行：断言 `resolveCustomRecharge` 不再导出；删除旧自由额度用例
2. 从 `miniprogram/utils/rechargeOrder.js` 移除自定义金额解析，同步 cloudfunctions 四份副本
3. `createRechargeOrder` 去掉 `customAmount` / `loadAllPlans`
4. 充值页 JS/WXML/WXSS 仅保留档位选择确认

## 风险

- 已部署云函数未更新时，旧客户端若仍传 `customAmount` 会失败（预期；本任务零兜底）
- 四份 `rechargeOrder.js` 漏同步会导致导出不一致

## 验证思路

- `node --test tests/rechargeOrder.test.js`
- 静态检查：充值页与 create 云函数无 `自由额度` / `customAmount` / `resolveCustomRecharge`
