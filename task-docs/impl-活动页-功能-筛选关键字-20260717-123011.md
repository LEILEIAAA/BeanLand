# impl-活动页-功能-筛选关键字

## 实际改动

- 活动文档用选填字段 `keyword` 替换枚举 `category`
- 会员活动页筛选项：`全部` + `招募中` + 列表中出现的关键字（去重、按出现顺序）
- 后台活动编辑：分类下拉改为「筛选关键字」输入框
- 更新活动时云函数 `db.command.remove()` 清除旧 `category` 字段

## 关键决策

- 单关键字、精确匹配；空关键字只进「全部」
- 不迁移历史 `theme`/`game` 等枚举；需重新编辑补关键字

## 残留风险

- 云端已有活动若未补 `keyword`，会员页除「全部/招募中」外不会出现对应筛选项
