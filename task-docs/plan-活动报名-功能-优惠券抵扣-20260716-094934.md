## 目标

活动报名支持优惠券抵扣：选券、计价、余额/微信支付，券读写 `user_coupons`，行为对齐套餐购买。

## 范围

- In：`activityRegistration` 纯逻辑；`createActivityRegistration` / `payActivityNotify`；报名页选券 UI
- Out：发券规则；取消退券；小时券抵金额；混合支付

## 改动方案

- 纯函数：券规范化 / 活动名 scope 匹配 / `calcActivityQuote` / 草稿写入 `couponId`+`couponAmount`+实付分
- 云函数：按 couponId 读 `user_coupons`；余额直接 used；微信 hold，回调 used/金额不符释放
- 前端：`listMyCoupons` + 选券 + 实付展示；实付 0 强制余额通道

## 风险

- 部署前真机调云会失败

- 取消仍不退券（产品确认）
