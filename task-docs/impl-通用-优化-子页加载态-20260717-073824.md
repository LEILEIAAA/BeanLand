# 实现：子页面统一加载态

## 实际改动
- 新增全局组件 `page-loading`：转圈 + 点跳动 + 列表骨架 shimmer
- `app.json` 全局注册，17 个异步子页接入
- 空态仅在加载结束后展示；多页初始 `loading` 改为 `true` 避免首帧空白
- 抽出 `utils/pageLoading.js` 供骨架行数计算，并补单测

## 关键决策
- 用可复用组件而非各页散装「加载中…」文案，视觉与 Bean 石色体系一致
- 保留页头/筛选栏，仅列表区替换为骨架，减少跳动感

## 变更文件
- `miniprogram/components/page-loading/*`
- `miniprogram/utils/pageLoading.js`
- `miniprogram/app.json`
- 会员：coupons / packages / records / stamps / works / appointments / seat-sessions
- 店主：appointments / activity-registrations / timer / timer-history / coupons / package-redeem / members / members/detail / transactions

## 验证结果

```
node --test tests/pageLoading.test.js
# pass 1 / fail 0
```
`page-loading` 已出现在 17 个 wxml；`app.json` 全局注册确认。

## 残留风险
- 预约登记页、充值页、路线页为表单/静态为主，未强加全页骨架
- 真机动画观感需微信开发者工具目视确认
