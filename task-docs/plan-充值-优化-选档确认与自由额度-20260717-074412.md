# 计划：充值页选档确认与自由额度

## 目标

充值页改为「点选档位 → 底部确认充值」；新增自由额度（最低 1 元）；手输金额向下取最近档送赠金。

## 范围

- In：`rechargeOrder` 纯逻辑、`createRechargeOrder` 云函数、充值页 UI、相关副本同步、单测
- Out：管理端代充改版、调试档数据清理、退款

## 现状

- 每档独立「微信支付」按钮，点选即下单
- `createRechargeOrder` 仅接受 `planId`

## 改动方案

1. `resolveCustomRecharge(plans, amount)`：校验 ≥1 元；向下匹配最高档取 `bonusAmount`；未命中赠送 0
2. 云函数：`customAmount` 与 `planId` 二选一；自定义单 `planId='custom'`，金额/赠金按解析结果快照
3. 前端：档位卡 +「自由额度」可点选；底栏单一确认；自定义显示输入与实付/赠送/到账预览

## 风险

- 云函数副本未同步 → 规则前后端不一致（同步四份 `rechargeOrder.js`）
- 调试档仍在库中时，自由额度 ≥0.02 会命中其赠送（约定上线前改档）
