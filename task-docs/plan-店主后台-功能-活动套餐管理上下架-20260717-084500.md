# 计划：店主后台活动/套餐管理（CRUD + 上下架）

- 状态：done
- 创建：20260717-084500
- 关联 impl：impl-店主后台-功能-活动套餐管理上下架-20260717-084500.md（完成后写）

## 目标

在店主后台新增「内容配置」能力：管理员可对活动、套餐做完整增/改/删，并支持上下架（下架后会员端彻底看不到）。

## 范围

- 云函数：新增 `listPackages`、`adminListPackages`、`adminSavePackage`、`adminListActivities`、`adminSaveActivity`；改造 `listActivities` 增加在架过滤。
- 小程序：新增后台 4 页（套餐列表/编辑、活动列表/编辑）；看板加分组入口；会员端套餐读取改走云函数并按在架过滤。
- 数据：`packages`/`activities` 集合与 seed 增加 `onShelf`（布尔）、`sortOrder`（数字）字段。
- 共享逻辑：套餐/活动表单归一化与校验模块，test-first。

不在本次范围：图片上传、富文本、批量导入、活动 `registeredCount` 的手工订正逻辑（沿用现值只读展示）。

## 现状

- 活动：`activities` 集合 → `listActivities` 云函数（公开，全量无过滤）；会员页 `pages/activities/index` 全量展示。
- 套餐：`packages` 集合 → 小程序端 `api.getPackages()` **客户端直连读库**；会员页 `pages/packages/index` 全量展示。
- 无任何写入口；管理员鉴权范式：各 admin 云函数 `assertAdmin(openid)` 查 `admins` 集合。
- 看板菜单配置化：`miniprogram/utils/adminDashboardMenu.js`。
- 测试：`node:test`，用例在 `tests/*.test.js`，共享逻辑与云函数目录同放。

## 数据模型

两实体统一新增：
- `onShelf: boolean` —— true=上架可见，false=下架隐藏（与活动生命周期 `status` 正交）。
- `sortOrder: number` —— 后台排序，越小越前。

套餐可编辑字段：id、name、price、weekendPrice、weekdayPrice、targetAudience、durationMinutes、overtimeRule、includedItems[]、isRecommended、badge、skipOpeningDiscount、onShelf、sortOrder。

活动可编辑字段：id、name、price、capacity、status（生命周期）、onShelf、startAt（日期+时间→epoch ms, Asia/Shanghai）、scheduleText、timeText、audience、content、includes[]、notice、sortOrder。`registeredCount` 只读。

## 改动方案

1. 共享校验模块（test-first）：
   - `cloudfunctions/adminSavePackage/packageForm.js`：`normalizePackageInput`、`validatePackage`、`buildPackageDoc`。
   - `cloudfunctions/adminSaveActivity/activityForm.js`：`normalizeActivityInput`、`validateActivity`、`buildActivityDoc`（含 startAt 组装/拆解）。
2. 云函数（均带 assertAdmin，save 用 action 路由 create/update/delete/setShelf）。
3. `listActivities` + `listPackages` 会员侧只回 `onShelf===true`。
4. 会员端 `api.getPackages()` 改调 `listPackages` 云函数（下架安全隐藏）。
5. 后台页面：列表（含上下架开关、编辑入口、新建按钮）+ 编辑表单（数组行增删、活动时间选择器、双价说明）。
6. 看板加「内容配置」分组：套餐配置 / 活动配置；`app.json` 注册 4 页；`cloudbaserc.json` 登记 5 个新函数。

## 风险

- 套餐历史直连读库路径切换：需保证 `listPackages` 回退与既有 `decoratePackages` 字段兼容。
- 活动 startAt 时区换算（复用 seed `chinaLocalMs` 思路）。
- 数组字段（includedItems/includes）小程序表单增删行 UX。
- 新建记录 id/排序：允许自定义 slug，空则用自动 `_id`，排序靠 `sortOrder`。
- seed fallback 掩盖空态：admin 写库后以库为准。
