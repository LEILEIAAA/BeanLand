# impl-会员设置-修复-整行热区

**对应计划：** `task-docs/plan-会员设置-修复-整行热区-20260717-215804.md`

## 实际改动

- `.set-row-label` / `.set-row-value`：`pointer-events: none`，避免右侧内容吃点击。
- `.set-row-hit`：`z-index: 2`，整行覆盖层置顶接收原生按钮事件。
- `.set-nickname-input`：`pointer-events: auto`，昵称仍可点编辑。

## 关键决策

- 根因是右侧 value 层叠挡在透明 `button` 之上，不是业务逻辑。
- 协议等 `tappable` 行：子节点穿透后由行 `bindtap` 接收，无需改 wxml。
