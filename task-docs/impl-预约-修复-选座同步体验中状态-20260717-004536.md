# impl-预约-修复-选座同步体验中状态

## 实际改动

开台/维护写入的现场占用无 `date`/`timeSlot`，预约选座原先只按时段查询过滤，导致「体验中」座位仍可选。现已在占用构建与加载两侧对齐座位管理现场状态。

## 关键决策

- 无时段字段的 `in_use` / `maintenance` 视为全局现场占用，选座与确认排座一律不可用
- 通过 `mergeOccupancyDocs` 合并时段占用与现场占用，按 `_id` 去重
