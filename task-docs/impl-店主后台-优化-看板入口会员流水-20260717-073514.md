# 实现：店主看板入口重排 + 会员管理 + 储值流水

## 实际改动

- 看板去掉底部统计，入口按：座位/订单 → 预约/活动 → 套餐/优惠券 → 会员/流水
- 「活动报名管理」→「活动管理」，「优惠券核销 / 发放」→「优惠券管理」
- 新增会员管理列表/详情（含等级标签）
- 新增储值流水页（全部/充值/消费/退款 + 收入/支出/净额/笔数）
- 云函数 `adminListMembers`、`adminListMemberTransactions`

## 关键决策

- 流水分类按 `member_transactions.type`（recharge/consume/refund），展示标题复用 `transactionTitle`
- 会员等级读 `members.tier`，展示走既有 `tierLabel`
- 详情按 `memberId` 直查，不依赖列表缓存
