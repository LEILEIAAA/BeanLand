# 计划：子页面统一加载态

## 目标
全部异步子页在数据加载完成前展示统一、美观的加载态，避免空白页或误显「暂无数据」。

## 范围
- 新增全局组件 `page-loading`（骨架屏 + 轻量指示器）
- 接入会员/店主侧列表与详情类异步子页
- 空态仅在 `loading === false` 后展示

## 非范围
- Tab 主页（首页/活动/套餐/会员）首屏大改
- 提交中 `wx.showLoading` 交互替换

## 改动方案
1. 创建 `miniprogram/components/page-loading`
2. `app.json` 全局注册
3. 各子页 wxml：`wx:if="{{loading}}"` 显示组件，列表/空态跟在 `wx:elif` / `wx:else`
4. 缺初始 `loading: true` 的页面补上（首屏即有态）

## 验证思路
- 组件文件齐全、全局注册存在
- 关键异步子页 wxml 含 `page-loading`
- 空态条件带 `!loading`

## 执行状态
- status: `done`
- 验证：`node --test tests/pageLoading.test.js` 通过；17 个子页已挂 `page-loading`
