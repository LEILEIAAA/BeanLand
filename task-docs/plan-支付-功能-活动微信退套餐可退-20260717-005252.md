# plan：活动微信自动退款 + 套餐未核销可退

## 执行状态

`completed`

## 目标

活动微信取消走 `cloudPay.refund`；套餐 `fulfilled` 未过期支持会员主动原路退；过期后仅自动退。

## 范围

- In：活动取消/重试退款、套餐会员退、状态机与单测、小程序文案与按钮、`cloudbaserc` 注册
- Out：店主代退套餐、手续费、充值退款、部署上线（本轮交付代码+单测）

## 现状

- 活动微信取消 → `refund_pending`，店主人工确认改状态，不调退款 API
- 套餐仅过期自动退（余额懒结算 + `expirePackageOrders` 微信退）

## 改动方案

1. 领域：`packagePurchase` 增加 `canUserRefundPackageOrder` / `beginUserPackageRefund` / `complete*` / `mark*`
2. 活动：`cancelActivityRegistration` / `adminConfirmActivityRefund` 调微信退款；失败保留待退
3. 新云函数 `refundPackageOrder`
4. 列表/UI：套餐未使用可退；退款记录 Tab 含主动退；活动文案与店主「重试退款」

## 风险

- 微信退款依赖 `subMchId` 与商户权限；失败单靠重试
- 多份云函数内嵌 `packagePurchase.js` 需同步拷贝
