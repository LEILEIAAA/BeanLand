## 实际改动

### 数据模型
- `packages`/`activities` 均新增 `onShelf`（布尔，下架隐藏）、`sortOrder`（数字，升序）。
- `miniprogram/data/seed.js`：用 `.map()` 给两组种子注入默认 `onShelf:true`、`sortOrder=(index+1)*10`。

### 共享逻辑（test-first）
- `cloudfunctions/adminSavePackage/packageForm.js`：normalize/validate/buildDoc + slugify + 数组解析。
- `cloudfunctions/adminSaveActivity/activityForm.js`：同上 + `chinaDateTimeToMs`/`msToChinaDateTime`（UTC+8 换算）。
- `miniprogram/utils/adminContentForm.js`：小程序侧时间换算（编辑页拆解 startAt、列表展示）。
- 测试：`tests/packageForm.test.js`、`tests/activityForm.test.js`、`tests/adminContentForm.test.js`。

### 云函数
- `listPackages`（公开）：仅回 `onShelf!==false`，按 sortOrder 升序。
- `adminListPackages` / `adminListActivities`（管理员）：全量含下架。
- `adminSavePackage` / `adminSaveActivity`：action 路由 create/update/delete/setShelf，均带 assertAdmin；create 建集合、活动 create 初始化 registeredCount。
- `listActivities`：新增 `onShelf!==false` 过滤 + sortOrder 排序。

### 前端
- 后台新页：`pages/admin/packages/{index,edit}`、`pages/admin/activities/{index,edit}`（各 4 文件）。
  - 列表页：新建按钮、上/下架切换、编辑、删除（带二次确认）。
  - 编辑页：套餐双价/时长/包含内容(多行)/推荐/开业折扣/上架开关；活动状态 picker、日期+时间 picker、名额、包含内容、须知、上架开关。
- `miniprogram/utils/api.js`：`getPackages` 改走 `listPackages` 云函数（下架安全隐藏，seed 回退亦过滤）；新增 4 个 admin API 并导出。
- `miniprogram/utils/adminDashboardMenu.js`：新增「内容配置」分组（活动配置/套餐配置），置于末尾。
- `miniprogram/app.json`：注册 4 个新页面。
- `cloudbaserc.json`：登记 5 个新云函数。

## 关键决策
- 上下架用独立 `onShelf` 布尔，与活动生命周期 `status` 正交，避免语义耦合。
- 套餐读取从「客户端直连库」改为 `listPackages` 云函数，满足「下架前端彻底不可见」的安全要求。
- 缺失 `onShelf` 的历史/种子数据按可见处理（`!==false`），避免迁移不全导致全量隐藏；新建记录始终显式写入。
- save 云函数用 action 单入口，减少函数数量、对齐 `adminUpdateAppointment` 范式。
