# plan-会员注册-修复-拦截偶发失效

## 目标

未完成三项注册（头像+昵称+手机号）时，前端稳定拦截并跳转注册页，后端拒绝预约与支付；消除「有时拦有时不拦」。

## 范围

- `miniprogram/utils/memberRegisterGate.js`：打开失败立即解锁；锁住且栈上无注册页时可重试
- 预约入口/页：`member/appointments` 前置门禁；预约页未就绪隐藏表单；`onShow` 复检；充值改完整注册判定
- `cloudfunctions/common/memberRegistration.js` + 复制到预约/活动报名/套餐/充值云函数
- 测试：`tests/memberRegisterGate.test.js`、`tests/memberRegistrationCloud.test.js`

## 现状

- 前端 `openMemberRegister` 在 `pendingOpen` 时静默 `return false`，预约页仍渲染表单
- `createAppointment` 只认 members 存在；支付类只验手机号
- `ensureMember` 会建空壳会员，后端门禁被绕过

## 改动方案

1. 加固 `openMemberRegister`：`fail` 立即清锁；`pendingOpen` 且栈无注册页时允许再次 navigate
2. 统一前端门禁入口；预约页 `memberReady` 未真时不展示可提交表单
3. 云函数 `assertMemberRegistered` 与小程序 `isRegistrationComplete` 同口径
4. 充值页改 `needsMemberRegister`，不再仅 `canRecharge`

## 风险

- 已有「仅绑手机号」的老用户会被挡，需完成头像昵称（符合产品确认口径）
- 云函数需重新部署后后端门禁才生效
