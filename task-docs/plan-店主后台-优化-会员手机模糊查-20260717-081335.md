# 计划：店主后台会员手机号模糊查询

## 目标

店主后台所有会员手机号查找支持模糊匹配：尾号、中间片段、完整号码均可命中。

## 范围

- `cloudfunctions/adminFindMember`：手机号正则由前缀 `^` 改为包含匹配
- `cloudfunctions/adminListMembers`：同上
- `miniprogram/pages/admin/package-redeem`：去掉必须 11 位校验
- 充值 / 发券 / 套餐核销 / 会员列表：placeholder 改为「手机号或尾号」提示

## 非范围

- 不改昵称搜索逻辑
- 不改列表展示里的「尾号」脱敏文案
- 不改会员端查找

## 现状

- 两处云函数数字关键词使用 `phone: RegExp(^keyword)`，仅前缀命中，尾号搜不到
- 套餐核销页前端强制 `/^1[3-9]\d{9}$/`

## 改动方案

1. 抽出可测纯函数 `buildPhoneSearchPattern(keyword)`（含 escape，无 `^` 锚点）
2. `adminFindMember` / `adminListMembers` 共用该 pattern
3. 前端：空串仍提示；非空即查；文案提示可尾号

## 风险

- 短尾号（如 1 位）可能命中较多；现有 limit 20/50 可接受
- 需重新部署两云函数才生效

## 验证思路

- 单元测试：完整号 / 尾号 / 中间片段 / 转义字符
- `node --test tests/memberSearch.test.js`
