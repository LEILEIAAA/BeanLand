# 实现：会员详情脏状态修复

## 实际改动

- 新增 `adminMemberDetail` 纯函数：按 id 精确取会员、构建详情重置态（禁止 `list[0]`）
- 详情页进入即置空 `member` / `transactions`，用实例 `_memberId` + 请求序号防串数据
- 切换流水筛选时先清空列表再拉取
- 列表跳转对会员 id 做 `encodeURIComponent`

## 关键决策

- 取会员必须 id 匹配，匹配失败视为不存在并清空，不回落列表首条
- 加载开始即清空展示字段，避免上一会员残留

## 变更文件

- `miniprogram/utils/adminMemberDetail.js`（新）
- `miniprogram/pages/admin/members/detail.js`
- `miniprogram/pages/admin/members/index.js`
- `tests/adminMemberDetail.test.js`（新）
