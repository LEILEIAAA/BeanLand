# 实现：会员详情嵌入储值流水

## 实际改动

- 云函数 `adminListMemberTransactions` 支持可选 `memberId`：查会员 `_openid` 后过滤流水
- 纯逻辑新增 `filterTransactionsByOpenid`（空 openid → 空列表；有值按精确匹配）
- 会员详情页嵌入「储值流水」区块：类型筛选（全部/充值/消费/退款）+ 列表展示

## 关键决策

- 复用既有流水云函数，不新建接口，保证与全店「储值流水」口径一致
- 详情页不做时间筛选与顶部汇总（按确认方案 B）
- fallback 查询路径仅在有 `memberOpenid` 时做内存 openid 过滤，避免全店查询被误清空
