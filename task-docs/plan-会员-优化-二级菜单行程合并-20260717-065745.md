# 计划：会员二级菜单重排 + 行程合并

## 目标

- 会员页快捷入口按「资产 → 行程 → 历史」重排
- 「我的预约」与「我的活动报名」合并为「我的行程」单入口（页内双 Tab）

## 范围

- `miniprogram/utils/memberActions.js`：入口顺序与合并 key
- `tests/memberActions.test.js`：断言新顺序与合并
- `miniprogram/pages/member/schedule/*`：新建行程页
- `miniprogram/pages/member/index.js`：路由
- `miniprogram/app.json`：注册 schedule，移除旧两页
- 删除 `appointments` / `activity-registrations` 会员子页

## 非范围

- 不合并套餐/优惠券、消费明细/到店记录
- 不改店主后台入口逻辑

## 改动方案

新顺序：`packages` → `coupons` → `schedule` → `seatSessions` → `records` →（admin）

行程页 Tab：`appointments`（开拼预约）/ `activities`（活动报名），沿用原两页交互与取消逻辑。
