## 部署清单（人工）

1. 云库新建集合 `recharge_orders`（建议唯一索引 `outTradeNo`）
2. 导入 `pay_config`（`subMchId` = 微信支付商户号），或改各函数内 `payConfig.subMchId`
3. 云开发控制台开通微信支付，回调函数选 `payRechargeNotify`
4. 部署：`ensureMember`、`getPhoneNumber`、`getMyMember`、`listMyTransactions`、`createRechargeOrder`、`payRechargeNotify`、`getRechargeOrder`、`adminRecharge`、`adminFindMember`
5. 确认 `recharge_plans` / `members` / `member_transactions` / `admins` / `member_tier_rules` 已导入
6. 真机：注册手机号 → 选档支付 → 余额与流水；店长代充同样出现订单+流水

## 残留风险

- 未配置 `subMchId` 时下单返回 `PAY_CONFIG_MISSING`
- 支付回调与前端轮询存在短暂延迟；极端并发下订单状态依赖二次读防重入，非事务
- 云函数目录内 common 副本需与 `cloudfunctions/common` 保持同步
