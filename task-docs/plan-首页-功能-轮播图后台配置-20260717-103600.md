# 首页轮播图后台配置

## 目标
店主后台新增「首页轮播」配置功能，可管理首页 hero 轮播图（图片 + 对应文案 caption），会员端首页读取该配置渲染。

## 现状
- 首页 `pages/home/index.js` 的 `HERO_PHOTOS` 硬编码 3 张本地图 + caption，首页未读云端 `store`。
- 后台已有成熟「内容配置」模式：列表/编辑页 + `adminSaveXxx` 云函数 + `api.js` 封装；图片走 `wx.cloud.uploadFile`。
- `api.getStore()` 读取 `store/main` 文档（客户端 db 读）。

## 改动方案
- 数据模型：`store/main` 增加 `heroPhotos: [{ src, caption }]`。`src` 可为本地路径或 `cloud://` fileID。
- 共用归一化：新增 `miniprogram/utils/homeBanners.js` 与云函数内 `homeBanners.js`（normalize/validate）。
- 首页：`onLoad` 读云端 `store.heroPhotos`，非空则覆盖默认（默认取 seed.store.heroPhotos）。
- 云函数：新增 `adminSaveHomeBanners`（admin 校验 + upsert store/main.heroPhotos）。
- 后台页：新增 `pages/admin/home-banners/index`（单配置编辑：增删/排序/换图/文案）。
- 菜单：`adminDashboardMenu` 内容配置分组加「首页轮播」；`app.json` 注册页面。
- api：新增 `adminSaveHomeBanners` 封装。

## 风险
- store/main 文档可能不存在 → 云函数需 upsert（get 判断后 add(_id:main) 或 update）。
- 首页 onShow 频繁触发 → 放 onLoad 一次性加载，避免打断轮播。

## 验证思路
- 微信开发者工具编译无报错；ReadLints 无新增错误；逻辑复核归一化/校验与 upsert 路径。
