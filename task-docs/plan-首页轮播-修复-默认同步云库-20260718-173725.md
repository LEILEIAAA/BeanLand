# 首页轮播默认同步云库

## 目标
体验版云库 `store/main.heroPhotos` 为空时，将包内默认轮播写入云库，使后台与会员首页同源读云。

## 范围
- `miniprogram/utils/homeBanners.js`：同步判定/载荷
- `miniprogram/pages/admin/home-banners/index.js`：加载时空库则 save 默认
- `tests/homeBanners.test.js`：覆盖同步判定

## 现状
- 首页 `resolveHomeHeroPhotos` 空则回落本地默认，云库仍空
- 后台只读云端 normalize，故显示无数据

## 改动方案
- 新增 `planHomeBannerCloudSync(cloudList)`：非空不写；空则 `needsSync: true` + 默认 banners
- 后台 `loadBanners`：get → 若 needsSync 则 `adminSaveHomeBanners({ action:'save', banners })` → 展示结果

## 风险
- 需管理员身份才能 save；非管理员打开页不会写入（符合权限）
- 本地路径 `/assets/...` 写入云库合法，与首页默认一致

## 验证思路
- `node --test tests/homeBanners.test.js`
- 逻辑复核：空→写默认；非空→不覆盖
