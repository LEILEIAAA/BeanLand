# plan-首页-修复-活动封面加载回退

**执行状态：** `done`

## 目标

首页「近期活动」海报封面在 `coverImage` 非法或云文件加载失败时，回退到本地 `COVER_POOL`，不再只剩灰底。

## 范围

- 抽出共用封面解析：`resolveActivityCover` / `fallbackActivityCover`
- `homeFeatured` 与活动页装饰逻辑改用该解析
- 首页、活动页海报 `<image>` 增加 `binderror` 回退

## 非目标

- 不改海报布局与样式
- 不改活动后台上传流程
- 不清理云端测试活动数据（如 `66666`）

## 改动方案

1. 新增 `miniprogram/utils/activityCover.js`：合法前缀（`cloud://` / `/` / `http(s)://`）才采用 `coverImage`，否则按槽位取 `COVER_POOL`
2. `homeFeatured.decorateHomeActivity` 与 `activities/index.js` 的 `decorateActivities` 改用上述函数
3. 首页 / 活动页 `binderror` 将对应条目 `cover` 写回 `fallbackActivityCover(index)`

## 风险

- `binderror` 若兜底图也失败可能循环；本地素材路径已知可用，风险低
- 活动页与首页需共用同一解析，避免再次漂移

## 验证思路

- `node --test tests/activityCover.test.js tests/homeFeatured.test.js`
- 断言：空/非法 cover → 本地池；合法 cloud/本地路径保留；加载失败回退函数返回池内路径
