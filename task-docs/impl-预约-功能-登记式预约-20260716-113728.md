# impl · 预约 · 登记式预约

**Nova run：** `20260716-113708`

## 实际改动

1. **纯函数** `miniprogram/utils/appointmentRegistration.js`：今明日期、登记校验、状态机、确认选座字段、占用文档构建。
2. **座位汇总** `seatSession.buildReservationsBySeatId`：支持 `arrived` 占用与 `readyToOpen`；座位管理展示「待开台」。
3. **云函数**：`createAppointment` / `listMyAppointments` / `cancelAppointment` / `adminListAppointments` / `adminUpdateAppointment` 由 stub 改为真实写入；确认写 `reserved` 占用，到店同步 `arrived`。
4. **C 端预约页**：去掉用户选座；今/明二选一；手机预填会员号；提交登记。
5. **店主确认选座**：`mode=assign` 复用选座 UI，座位源 `api.getSeats()`。
6. **店主/会员预约列表**：接云列表与确认/拒绝/到店/取消。

## 关键决策

- 用户登记不占座；仅店主确认选座后写占用。
- 座位与座位管理同源（`api.getSeats()` / 云库 `seats`）。
- 到店不自动开台，同步为待开台后由座位管理开台。
