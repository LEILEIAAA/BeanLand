# plan-活动报名-优化-已生效筛选

## 目标

活动管理（报名列表）在保持票务制（无核销）前提下，增加状态筛选项「已生效」：已支付且活动开场时间已到。

## 范围

- 改：`miniprogram/utils/adminActivityRegistrationFilter.js`
- 改：`miniprogram/utils/activityRegistration.js`（判定 helper + resolve 筛选项）
- 改：`cloudfunctions/adminListActivityRegistrations/`（查 paid 后按活动 startAt 精炼；回填 isEffective）
- 改：`miniprogram/pages/admin/activity-registrations/index.js`（展示「已生效」标签）
- 改：`tests/adminActivityRegistrationFilter.test.js`、`tests/activityRegistration.test.js`

## 现状

- 筛选项：全部 / 已报名 / 已取消
- 报名无核销态；`paid` 在开场后仍为 `paid`，仅取消策略锁死
- 报名记录不存 `startAt`，需关联 `activities`

## 改动方案

1. Tab 增加 `{ key: 'effective', label: '已生效' }`
2. `isActivityRegistrationEffective(reg, startAt, now)`：`status===paid` 且 `startAt>0` 且 `now>=startAt`
3. `resolveAdminListStatusFilter('effective')` → 查 `paid`，带 `refine: 'effective'`
4. 列表云函数：批量取活动 `startAt`，标注 `isEffective` / `activityStartAt`；筛「已生效」时只返回生效行
5. 前端：`isEffective` 时 `statusLabel` 显示「已生效」
6. 「已报名」仍为全部 `paid`（含已生效子集）

## 风险

- 活动无 `startAt` 的报名不会进「已生效」（与取消「无开场时间不可取消」一致）
- 活动文档 `_id` / `id` 双键需同时建 map
