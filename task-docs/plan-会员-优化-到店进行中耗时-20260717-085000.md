# plan-会员-优化-到店进行中耗时

## 目标

进行中的到店记录展示「已进行 Xx分钟」（前置时钟 icon）；会员页「到店记录」入口有进行中时同步显示同文案角标。

## 执行状态

`done`

## 范围

- 改：`miniprogram/utils/seatSessionHistory.js`（进行中耗时文案）
- 改：`miniprogram/utils/memberActions.js`（入口 badge + clock）
- 改：会员页 / 到店记录列表页 wxml·wxss·js
- 测：`tests/seatSessionHistory.test.js`、`tests/memberActions.test.js`
- 不改云函数

## 方案

1. `formatActiveElapsedLabel(minutes)` → `已进行 45分钟` / `已进行 2小时` / `已进行 2小时25分`
2. `mapMemberSessionRow(row, now)` 进行中按 `startedAt` 算已用分钟并写入 `durationLabel`
3. `activeElapsedLabelFromSessions(list, now)` 取最新 active 的文案
4. 列表：进行中显示时钟 + `durationLabel`；已结束仍「时长 xxx」
5. 会员入口：`badge` + `badgeIcon: 'clock'`（CSS `.icon-clock`，与店主计时页一致）
