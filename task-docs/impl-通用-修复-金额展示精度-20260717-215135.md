# impl-通用-修复-金额展示精度

**关联计划：** `task-docs/plan-通用-修复-金额展示精度-20260717-215135.md`

## 实际改动

- `miniprogram/utils/money.js` 新增 `formatYuan`：先 `toFixed(2)` 再转字符串，整数裸显（`99`），有小数最多两位（`0.06`）
- 活动报名 / 套餐购买：余额、实付、抵扣、价签、弹窗文案走格式化字段
- 首页/活动列表/充值/后台会员搜索与流水/会员行程等裸绑金额统一格式化
- 删除各页本地重复 `formatYuan`，改为引用 `utils/money`

## 关键决策

- 整数不补 `.00`（产品确认）
- 比较与扣款仍用数值字段，展示与文案用 `formatYuan`
- `formatYuan2` 保留（固定两位），余额类展示改用 `formatYuan`

## 变更文件

- `miniprogram/utils/money.js` 及调用方（报名、套餐、首页、充值、后台、会员等）
- `tests/money.test.js`、`tests/adminMemberDisplay.test.js`、`tests/seatSessionHistory.test.js`
- 规格/计划：`docs/superpowers/specs/2026-07-17-money-display-precision-design.md`、`docs/superpowers/plans/2026-07-17-money-display-precision.md`
