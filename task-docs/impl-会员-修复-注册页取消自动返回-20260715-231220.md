# 实现：注册页取消自动返回会员

**对应计划：** `plan-会员-修复-注册页取消自动返回-20260715-231220.md`

## 实际改动

1. `bootstrap`：资料已完善时不再调用 `finishAndBack`。
2. 删除 `maybeFinish`；头像/昵称/手机号保存后仅 toast，不自动返回。
3. `finishAndBack` 仅由底部「完成注册并返回」(`onFinish`) 触发。
4. 注册页文案改为「三项齐全后点底部按钮返回会员页」。

## 变更文件

- `miniprogram/pages/member/register/index.js`
- `miniprogram/pages/member/register/index.wxml`

## 验证结果

- `nova_guard`：ok
- `node --test tests/memberProfile.test.js tests/wxProfile.test.js`：21 pass / 0 fail
- 静态确认：自动返回路径已移除，仅 `onFinish` → `finishAndBack`

## 残留风险

小程序端需真机/开发者工具点一次：资料齐全时进注册页应停留，点底部按钮才回会员页。
