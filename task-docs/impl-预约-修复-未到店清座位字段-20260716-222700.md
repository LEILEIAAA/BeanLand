## 实际改动

1. `buildNoShowFields` 增加清空 `seatIds` / `tableCode`，列表不再残留桌号。
2. `settleNoShowAppointments`：转 no_show 时写清空字段并删 reserved 占用；已是 no_show 仍有座位字段时补清，并幂等删占用。

4. `adminListSeatBoard`：内存过滤扩展为终态预约 ID，arrived 占用一并过滤。

- 展示层与结算层双保险：即使占用删除失败，座位看板也不再画出终态预约的时段。
