## 实际改动

- 套餐页 CTA 改为「立即购买」，弹层选券 + 余额/微信支付，不再跳转预约
- 纯逻辑 `packagePurchase.js`：券匹配、最优券、计价、订单草稿、券 hold/used
- 云函数：`purchasePackage`（余额）、`createPackageOrder` / `payPackageNotify` / `getPackageOrder`（微信）
- `memberCredit` 增加余额扣款与微信消费记账；`ensureMember` 新会员带 `coupons: []`
- `api.js` / `cloudbaserc.json` 注册新接口

## 关键决策

- 混合支付不做；实付为 0 走余额通道核销券
- 微信下单时 hold 券，回调成功后 used；金额不匹配则释放
- 会员无云端 coupons 时仅能原价购买（需入库券才可抵扣）
