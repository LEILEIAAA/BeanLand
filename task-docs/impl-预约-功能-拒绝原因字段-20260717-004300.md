# 实现：预约拒绝原因字段

## 实际改动

- 预约工具新增 `REJECT_REASON_PRESETS` / `assertRejectReason` / `buildRejectFields`
- `adminUpdateAppointment` 拒绝时校验并写入 `rejectReason`
- 店主预约管理：拒绝底部面板（快捷芯片 + 手输），列表展示拒绝原因
- 会员「我的预约」：已拒绝记录展示店主拒绝原因
- 各云函数本地 `appointmentRegistration.js` 已同步

快捷原因：`时段已满` / `人数超限` / `临时闭店` / `其他`

## 关键决策

- 拒绝原因必填，最长 80 字
- 快捷芯片填入输入框，可再编辑
- 历史无 `rejectReason` 的已拒绝单不展示原因行
