# impl-店主后台-优化-会员选中去重

## 实际改动

## 关键决策

- JS `selectedId` / `selectedLabel` 保留（套餐核销跳转开台仍依赖 `selectedLabel`）
- `timer` 不在范围
- 纯展示层，无单元测试；用静态 grep 验收
