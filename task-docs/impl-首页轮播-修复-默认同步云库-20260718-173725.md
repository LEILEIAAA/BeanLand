# 首页轮播默认同步云库 — 实现记录

## 实际改动
- `planHomeBannerCloudSync`：云端 `heroPhotos` 为空时规划写入 `DEFAULT_HERO_PHOTOS`；已有配置不覆盖。
- 后台「首页轮播」`loadBanners`：加载后若 `needsSync`，以管理员身份调用 `adminSaveHomeBanners` 写入云库，再展示。

- 同步触发点放在店主打开配置页：需 admin 权限，避免公开读接口写库。
- 写入内容与首页回落同源（包内 3 张工坊图），不另造种子。
