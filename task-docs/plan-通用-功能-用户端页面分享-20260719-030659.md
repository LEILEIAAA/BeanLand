# plan · 通用 · 功能 · 用户端页面分享

## 目标

用户端每个页面右上角「转发」「分享到朋友圈」可用；按规格定制标题与落地路径；后台不开。

## 范围

- 新增 `miniprogram/utils/share.js` + `tests/share.test.js`
- 接入全部非 admin 用户端页面 js/json
- 规格：`docs/superpowers/specs/2026-07-17-page-share-design.md`

## 现状

尚无 `onShareAppMessage` / `shareBehavior` / 分享 json 开关。

## 改动方案

公共 `resolveShareConfig` + `shareBehavior`；用户端挂 Behavior 并开 json 开关。

## 风险

- 活动报名分享依赖 `data.activity.name` / `activityId`，未加载完时标题回退「活动报名」
- Behavior 在 Node 测试环境需可 require

## 验证思路

`node --test tests/share.test.js`；扫描用户端接入与 admin 未接入。
