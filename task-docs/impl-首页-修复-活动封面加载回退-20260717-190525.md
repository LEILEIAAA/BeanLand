# impl-首页-修复-活动封面加载回退

**对应计划：** `task-docs/plan-首页-修复-活动封面加载回退-20260717-190525.md`

## 实际改动

- 新增 `activityCover`：校验封面地址（`cloud://` / `/` / `http(s)://`），非法则按槽位回退 `COVER_POOL`；加载失败用 `fallbackActivityCover` 换本地图。
- `homeFeatured` 与活动页装饰逻辑改用 `resolveActivityCover`。
- 首页、活动页海报 `<image>` 增加 `binderror`，失败时写回本地兜底图。

## 关键决策

- 非法字符串（空、`null`、`undefined`、临时 `wxfile://`）在解析阶段直接丢弃，不等加载失败。
- 合法但云文件损坏的 `cloud://` 仍依赖 `binderror` 回退。
