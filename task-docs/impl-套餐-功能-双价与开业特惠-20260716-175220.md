# impl-套餐-功能-双价与开业特惠

## 实际改动

1. 套餐目录替换为 4 档：
   - 周末单人无限体验 69.9 / 工作日 49.9
   - 周末双人同行体验 119.9 / 工作日 91.9
   - 周末亲子出行 79.9 / 工作日 59.9
   - 开业限时·三人同行一人免单 139.8 / 99.8（按单人档 ×2）
2. `store.packagePromo`：开业七天全场 8 折（`discountRate: 8`）
3. `packagePurchase` 新增按中国时区周末/工作日选价 + 开业折扣；云函数下单/余额购买同源计价
4. 套餐页改造：双价板、今日结算（含划线原价）、开业条、包含 chips
5. 首页主推映射改为新三档并展示工作日价

## 关键决策

- 结算价自动按「今天是否周末」选档，再乘开业 8 折；前后端一致
- 三人免一未给单独标价，按 2×单人双价落地
- 旧套餐（含包场）从套餐页移除；包场仍在活动

## 残留风险

- 云函数需重新上传后，线上购买才会按新计价（库已更新，未上传函数则仍可能用旧 `price` 逻辑）
- 开业 8 折目前由 `packagePromo.active` 开关控制，关停时改 store 即可
- `opening-trio`（三人同行一人免单）不叠加开业 8 折：`skipOpeningDiscount: true`
