# 文创拼豆手作店小程序 MVP 与开发计划

## 1. 文档目的

本文档用于确认文创拼豆手作店第一版小程序与后台管理系统的 MVP 范围，并形成后续开发执行计划。

当前业务背景：

- 门店距离开业约 7 天，必须优先服务开业冷启动。
- 核心目标是抓住暑期学生时间档，同时承接亲子、年轻女性、五月天粉丝等人群。
- 小程序不是单纯展示页，而是门店预约、会员储值、座位计时、活动报名、用户沉淀和后台运营的基础设施。

本 MVP 的核心原则：

> 先支撑开业经营闭环，再逐步扩展复杂功能。

---

## 2. 已确认的经营前提

### 2.1 门店基础信息

- 地址：杭州市拱墅区上塘路 259 号（假山路口）新青年广场 A 座
- 空间：loft，总 155 平
- 租金：3800 元/月
- 物业：500 元/月
- 电费：0.9 元/度
- 水费：免
- 位置：新青年广场 A 座顶楼
- 空间优势：采光好，落地窗，适合拍照和活动
- 楼内资源：棋牌室、培训机构、物业前台与保安关系资源

### 2.2 经营定位

> 以线下拼豆手作体验店为经营底座，以五月天粉丝社群作为主要裂变方向，并逐步沉淀成可长期拓展的情绪价值型手作品牌。

### 2.3 开业期重点用户

- 暑期学生
- 年轻女性
- 闺蜜/情侣/同学同行
- 小孩与亲子家庭
- 五月天粉丝及泛粉丝情绪消费用户
- 楼内棋牌室/培训机构带来的近场用户

### 2.4 空间与座位模型

已确认采用：

> 24-28 个日常体验位 + 32-40 人活动容量 + 分区式手作活动空间。

空间分区建议：

- 日常拼豆体验区
- 窗边拍照区
- 粉丝主题/作品墙
- 材料与成品展示区
- 活动可变区

## 3. 小程序 MVP 总体范围

第一版小程序采用：

> 用户端：展示 + 套餐 + 活动 + 预约 + 路线 + 会员中心  
> 后台端：预约管理 + 套餐管理 + 活动管理 + 座位计时 + 会员储值 + 消费记录 + 用户标签 + 基础数据看板

### 3.1 MVP 必须解决的问题

1. 用户能快速理解店铺定位和主推套餐。
2. 用户能预约套餐或活动。
3. 用户能清楚知道门店路线，尤其是如何到达新青年广场 A 座顶楼。
4. 店主能管理预约、场次、活动和座位占用。
5. 店主能记录用户、会员、储值余额和消费流水。
6. 店主能记录用户来源，为美团、小红书、朋友圈、楼内导流和粉丝社群做效果分析。
7. 系统能支持按套餐时长计时、续时、超时和补差价。
8. 系统能在开业初期沉淀用户资产，而不是只做一次性到店。

## 9. 开业当天最小操作流程

### 用户预约流程

1. 用户进入小程序
2. 浏览首页/套餐/活动
3. 选择套餐或活动
4. 填写预约信息
5. 查看预约确认和到店路线
6. 到店后由店主核销

### 到店计时流程

1. 店主在后台找到预约单
2. 标记已到店
3. 分配桌号
4. 点击开始计时
5. 系统显示预计结束时间
6. 如需续时，记录续时
7. 点击结束体验
8. 生成消费记录

### 会员储值流程

1. 用户注册/绑定会员
2. 店主选择充值档位
3. 录入支付方式
4. 系统增加本金余额与赠送余额
5. 生成充值记录和余额流水

### 消费扣款流程

1. 选择会员
2. 创建消费订单
3. 选择套餐/续时/补差价项目
4. 选择支付方式
5. 如使用余额，系统扣减余额
6. 生成消费记录和余额流水

## 11. 最终确认

本小程序 MVP 的第一目标是：

> 支撑门店开业 7 天内可预约、可到店、可计时、可储值、可消费记录、可沉淀会员。

第一版不是追求功能完整，而是确保开业核心经营动作不断链。

后续根据真实经营数据，再迭代美团承接、社群复购、库存管理、活动报名、数据看板和线上商城。
