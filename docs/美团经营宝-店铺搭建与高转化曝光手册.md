## 1. 行业经验：美团/点评休闲玩乐怎么涨量

### 1.1 曝光从哪来（按杠杆排序）

1. **类目与标签选对** — 用户搜「拼豆 / 手工 / DIY / 亲子手工 / 解压」必须能命中你。
2. **门店信息完整度 100%** — 头图、相册、营业时间、电话、地址导航、设施、公告。
3. **在售团单结构健康** — 有「引流款 + 利润款 + 社交款」，且工作日/周末价逻辑清晰。
4. **销量与评价起步** — 新店优先冲前 20～50 单真实核销 + 好评，算法才给附近/相关推荐。
5. **经营评分与商户通任务** — 后台「经营评分 / 经营参谋」红点任务尽量清完，否则限流。
6. **付费推广（已有计划 ADE59773069）** — 在素材与团单转化打磨后再加预算，否则烧钱买曝光不转化。
7. **内容分发** — 点评笔记 / 探店内容 / 短视频挂门店，补自然流量。

### 1.2 转化从哪丢（常见劝退）

- 封面不像「想去玩」，像库存图或空店。
- 标题堆词但无利益点（没写「材料全含 / 不限时 / 可合影」）。
- 团购价相对门市没有锚点，或细则里「另收费」太多。
- 适用人群/预约规则过严（需提前 1 天、不可改期、高峰加价写得吓人）。
- 相册没有「成品墙 / 座位氛围 / 情侣闺蜜场景」，信任不足。
- 评价 0 条时，详情页没有「到店流程 + FAQ」顶住犹豫。

### 1.3 拼豆/手工店品类打法（适配 Bean Land）

| 人群 | 搜词倾向 | 主推团单 | 封面场景 |
|------|----------|----------|----------|
| 情侣/闺蜜 | 双人手工、约会、解压 | 双人 2h / 双人无限时 | 两人同桌、成品合影 |
| 学生 | 便宜试玩、周末 | 单人 1h / 开业三人免单 | 学生价、轻松氛围 |
| 亲子 | 亲子手工、儿童 | 亲子无限时 | 亲子成品、安全指导 |
| 个人解压 | DIY、拼豆体验 | 单人无限时 | 作品特写、材料特写 |

开业窗口（seed：7.18–7.24「三人同行一人免单」）优先砸曝光与销量，再切常规结构。

- [ ] **门店头图 + 相册 ≥ 20 张**：头图 1 张「人+作品+店招」；相册分组建议：门头、环境座位、材料区、成品墙、双人场景、亲子场景、夜景/灯光。
- [ ] **设施标签**：空调、洗手间、可拍照、适合情侣/亲子、提供材料等能勾尽勾。
- [ ] **公告**：一句话 — 营业时段 + 是否需预约 + 材料是否全含。

### 阶段 B：团单结构（决定点击与购买）

路径：**团单管理** / 交易相关菜单。

建议与小程序套餐对齐的美团结构（价格以你后台最终审核价为准）：

| 角色 | 团单名方向 | 参考价（seed） | 作用 |
|------|------------|----------------|------|
| 引流入口 | 单人1小时尝鲜 | 工作日 15.9 / 周末 24.9 | 低决策门槛，冲销量与评价 |
| 主转化 | 双人2小时 | 工作日 55.9 / 周末 69.9 | 当前后台已在改价审核，做主推 |
| 高客单 | 双人无限时 / 单人无限时 | 91.9–119.9 / 49.9–69.9 | 吃足停留与客单 |
| 亲子 | 亲子无限时 | 59.9–79.9 | 占亲子流量坑 |
| 开业爆款 | 三人同行一人免单 | 99.8–139.8 | 限时冲榜，写清日期 |

团单文案硬规则：

1. **标题**：`人群 + 时长/权益 + 核心利益`  
   例：`双人2小时拼豆体验｜材料全含·可合影·现场指导`
2. **副标题/亮点**：3 条以内，全是「用户在意的」：材料全含、图纸任选、成品熨烫/包装、当日不限时等。
3. **原价锚点**：门市价略高于团购价，差价看得见但不离谱。
4. **套餐明细**：逐条写清「含什么 / 不含什么」；避免「材料另计」藏细则。
5. **使用规则**：尽量「免预约或当天电话确认」「节假日通用或明确加价」「过期退/随时退」——退改友好显著抬转化。
6. **封面**：竖版/横版按后台规范；主视觉禁止纯文字海报；必须有真实店内图。

### 阶段 C：评价与信任（决定敢不敢买）

路径：**评价管理**。

- [ ] 核销后话术引导好评（不违规刷评；真实体验 + 成品图）。
- [ ] 差评 2 小时内回复：致歉 + 解决方案 + 邀请私了补偿。
- [ ] 好「大众点评 / 美团」双端，避免一端荒废。

### 阶段 D：曝光加速（在转化打磨后加码）

路径：**推广中心 / 我的推广**、**营销活动**、**经营参谋**。

- [ ] 先看清已生效计划 `ADE59773069`：出价、定向（附近/关键词）、落地团单是否主推「双人2h」或开业爆款。
- [ ] 关键词包建议：拼豆、手工DIY、亲子手工、情侣约会、解压手工、拱墅手工、新青年广场。
- [ ] 每日看：曝光→点击→购买→核销；CTR 低改封面标题，转化低改价格/规则，核销低查预约摩擦。
- [ ] 经营参谋红点任务清完（完整度、回复率、活动报名等）。

### 阶段 E：私域承接（曝光变资产）

## 3. 高转化团单页检查表（上架前过一遍）

**5 秒测试**：陌生人只看封面+标题，能否说出「这是拼豆手工店、两人能玩、材料好像含了」？

| 检查项 | 合格标准 |
|--------|----------|
| 封面 | 真实场景 + 成品清晰 + 无杂乱水印 |
| 标题 | 含品类词 + 人数/时长 + 1 个利益点 |
| 价格 | 入口款足够低；主推款性价比一眼懂 |
| 亮点 | ≥3 条可核对的权益，无空洞形容词 |
| 细则 | 另收费 ≤1 项且提前写明；退改友好 |
| 相册 | 环境+作品+社交场景齐全 |
| 评价 | 有则置顶晒图好评；无则详情写「到店 4 步流程」 |
