# 店主后台会员查找：去掉「当前选中」重复展示

## 目标

店主后台「手机号查找会员」流程中，会员结果行已有选中高亮时，不再额外展示「当前选中」块，消除信息重复，让页面更干净。

## 范围

| 页面 | 路径 |
|------|------|
| 套餐核销 | `miniprogram/pages/admin/package-redeem/` |
| 优惠券核销/发放 | `miniprogram/pages/admin/coupons/` |
| 转账代充 | `miniprogram/pages/admin/recharge/` |

不在范围：开台计时 `timer`（会员查找 UI 不同）。

## 方案

1. 删除三页 WXML 中「当前选中」整块（label + 展示框）。
2. 选中态仅由会员行 `.member-row.active` 表达。
3. JS 中 `selectedId` / `selectedLabel` 保留，供后续业务（加载列表、跳转开台等）使用。
4. 套餐核销页 `.member-row.active` 补圆角，使选中块更清晰；优惠券 / 代充已有圆角或描边，不强制统一视觉语言以外的大改。

## 非目标

- 不改查找 / 点选 / 核销 / 充值业务逻辑
- 不抽公共组件
- 不改 timer 页

## 验收

- 三页查找并选中会员后，页面上只有一处会员身份展示（结果行高亮）
- 选中后下游操作仍可用（套餐列表 / 券面板 / 充值表单）
