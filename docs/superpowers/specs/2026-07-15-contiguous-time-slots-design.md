# 连续时段多选设计规格

> 日期：2026-07-15  
> 状态：已确认（方案 A + 同座贯穿 + 末场结束）  
> 范围：用户端预约页时段选择；seed / 展示样例同步；核心工具函数可测

## 1. 目标

1. 预约时段改为**墙钟无缝**的 2 小时场次。
2. 用户可**连选多段**，必须保持连续；同批座位在所有已选时段占库存。
3. 预计结束时间取**最晚一场的结束时刻**。

## 2. 已锁定决策

| 议题 | 决策 |
|---|---|
| 时段表 | 方案 A：`10:00-12:00` … `20:00-22:00` 每场 2h 贴齐 |
| 多选约束 | 墙钟无缝连续；只能从两端伸缩，不可拆中间 |
| 选座 | 同座贯穿；座位态按已选时段占用**并集**（任一时段不可约则不可约） |
| 结束时间 | 末场结束点；本版不改套餐计价 |
| 数据 | `timeSlots: string[]`；展示区间 `首开-末闭` |

## 3. 非目标

- 跳段多选、分时段不同座位、价格按段数倍增、改店主计时页交互深度

## 4. 领域规则

### 4.1 时段表

```
10:00-12:00
12:00-14:00
14:00-16:00
16:00-18:00
18:00-20:00
20:00-22:00
```

相邻两场满足：上一场 end === 下一场 start。

### 4.2 选择状态机

- 空选 → 点任意场 → 选中该场（至少保留 1 场时：单独再点取消无效，保持 1 场）
- 已选连续区间 `[i..j]`：
  - 可加 `i-1` 或 `j+1`（且墙钟相邻）
  - 可减 `i` 或 `j`（减到只剩 1 场后不可再清空）
  - 点中间已选 / 非相邻未选 → 拒绝，toast「请选择连续时段」

### 4.3 库存

键仍为 `(date, timeSlot, seatId)`。一次预约写入 `|timeSlots| × |seatIds|` 条占用。

### 4.4 摘要

- `timeSlot` 展示字段 = `formatSlotSpan(timeSlots)`（如 `14:00-18:00`）
- `expectedEndTime` = 解析末场 end

## 5. 验收

1. Chip 可连选相邻场，跳选失败。
2. 多选后座位图反映并集占用。
3. 确认摘要时间与预计结束正确。
4. `node --test` 相关用例全绿。
