# 金额展示精度设计

## 问题

JS 浮点运算产生长尾（如 `0.060000000000000005`），活动报名/套餐购买等页面直接把 `Number` 绑到 WXML，导致余额展示异常。

## 决策

- 展示统一走 `miniprogram/utils/money.js` 的 `formatYuan`
- 规则：先 `toFixed(2)` 收敛，再转为展示字符串；整数不带小数（`99`），有小数最多两位（`0.06` / `128.5`）
- 比较与扣款仍用数值字段；展示用 `*Text` 或已格式化字段
- `formatYuan2`（固定两位）保留给明确需要补零的场景；余额/价签类展示改用 `formatYuan`

## 范围

支付相关页（活动报名、套餐购买）及所有裸绑 `totalBalance` / `payAmount` / 价签的展示与弹窗文案。
