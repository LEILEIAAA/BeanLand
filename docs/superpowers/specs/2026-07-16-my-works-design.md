# 我的拼豆（作品墙）设计规格

**日期：** 2026-07-16  
**状态：** approved（用户确认规格）  
**关联决策：** 集章（激励）与作品墙（纪念）AB 独立；入口选会员页独立卡片（方案 A）

## 目标

为会员提供「我的拼豆」作品墙：上传成品照、按时间浏览、删除自己的作品。与集章进度/兑换激励完全拆开，不把作品图当作集章 icon。

## 范围

### In

- 会员页「我的集章」卡正下方新增「我的拼豆」独立卡片（标题、副文案、作品数、最多 3 张缩略图或空态）
- 新页面 `/pages/member/works`：双列网格、大图预览、上传、删除
- 云集合 `works` + 云存储图片；云函数读写（列表 / 上传落库 / 删除）
- 仅当前用户可见自己的作品（首版无广场）

### Out

- 作品图作为集章圆点 icon
- 底栏新增 Tab
- 发章业务 / `stamp_logs` 集合（另案）
- 公开广场、点赞评论、分享海报
- 作品与某次预约/集章的强绑定（首版不做关联字段）

## 信息架构

```
会员 Tab
├── 我的集章卡 → pages/member/stamps（A：激励）
├── 我的拼豆卡 → pages/member/works（B：作品）  ← 本规格
└── 快捷列表（优惠券 / 消费明细 / 我的预约 …）
```

- 两卡上下相邻、职责分栏，数据模型不共享。
- 集章详情可不加互跳；若加，仅弱文案链到作品页，不作主入口。

## 交互

### 会员页卡片

| 元素 | 行为 |
|------|------|
| 标题 | 我的拼豆 |
| 副文案 | 把成品照留下来 |
| 右侧 | 作品数 `N`（无则 `0`） |
| 有作品 | 最多 3 张缩略图横排（按 `createdAt` 倒序取前 3） |
| 无作品 | 空态文案「还没有作品，去拍一张」 |
| 整卡点击 | `navigateTo` → `/pages/member/works/index` |

### 作品页

- 导航栏标题：我的拼豆；右上「上传」
- 主体：双列网格；点击缩略图 → `wx.previewImage` 大图
- 空态：短文案 + 主按钮「上传作品」
- 单条展示：图 + 可选备注 + 日期；支持删除（确认后删库并删云文件）
- 上传流：`wx.chooseMedia` / `chooseImage` → `wx.cloud.uploadFile` → 云函数写 `works` → 刷新列表与会员页预览

### 约束（首版）

- 单次上传 1 张；备注可选、短文本（建议 ≤ 40 字）
- 仅能删自己的作品（云函数校验 `_openid`）
- 不做压缩策略细则外的多图相册编辑器

## 数据

### 集合 `works`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_openid` | string | 归属用户（云自动/写入时带上） |
| `imageFileID` | string | 云存储 fileID |
| `caption` | string | 可选备注，默认可空串 |
| `createdAt` | number | 毫秒时间戳 |
| `updatedAt` | number | 毫秒时间戳 |

索引建议：`_openid` + `createdAt` 倒序查询。

### 云函数（与现有 `listMy*` / 单职责风格对齐）

| 云函数 | 职责 |
|--------|------|
| `listMyWorks` | 当前用户作品列表（`createdAt` 倒序；支持 `limit`，会员卡预览传 `3`） |
| `createWork` | 入参 `imageFileID` + 可选 `caption`；校验 openid 后写入 `works` |
| `deleteWork` | 入参 `workId`；校验归属后删文档，并尽量 `cloud.deleteFile` |

会员页预览只调 `listMyWorks({ limit: 3 })`；不在 `members` 文档冗余作品数组。

## 页面与文件（预期）

| 路径 | 职责 |
|------|------|
| `miniprogram/pages/member/index.*` | 增加拼豆卡 UI + 预览数据拉取 |
| `miniprogram/pages/member/works/*` | 作品墙页 |
| `miniprogram/app.json` | 注册 works 页 |
| `cloudfunctions/...` | 列表/创建/删除 |
| `tests/...` | 纯函数或云逻辑可测部分（如 caption 截断、列表映射） |

## 验证思路

1. 未登录/无 openid：云函数拒绝写删
2. 上传成功后：作品页出现新图；返回会员页卡片缩略图与计数更新
3. 删除后：列表与卡片同步减少；云文件不可再预览
4. 集章卡与拼豆卡互不影响（改作品不改变 `stampCount`）

## 残留风险 / 后续

- 云存储配额与未清理孤儿文件：删除路径必须尽量成对删 file
- 后续若要「到店打卡关联作品」，再加可选 `appointmentId`，本轮不加
- 广场/分享属独立规格
