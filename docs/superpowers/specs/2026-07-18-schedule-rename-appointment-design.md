# 我的行程 → 我的预约 文案设计

## 目标

用户侧将合并入口「我的行程」统一改称「我的预约」，开拼预约与活动报名成功后的引导文案指向「我的预约」。

## 文案对照

| 位置 | 新文案 |
|------|--------|
| 会员快捷入口 / 页标题 / 副标 | 我的预约 |
| 亮点卡标题 / kicker / foot | 我的预约 / 预约 / N 条预约待查看 |
| 页加载 tip | 预约加载中 |
| 开拼预约成功卡 | 店主确认排座后会通知你，前往我的预约查看。 |
| 活动报名成功 toast | 报名成功，前往我的预约查看 |
| 支付处理中 toast | 支付处理中，请稍后在「我的预约」查看 |

## 不改

- 页内 Tab：开拼预约 / 活动报名
- 路由 key `schedule`
- 法律协议中的通用「报名成功」表述
