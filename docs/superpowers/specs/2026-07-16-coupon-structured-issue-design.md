# 优惠券结构化发放 设计规格

**日期：** 2026-07-16  
**状态：** approved（用户确认执行）  
**方案：** 主类型 → 折扣类型 → 填变量（方案 A）

## 目标

店主发券取消全字段自定义（券名 / 面额 / 范围 / 有效天数），改为结构化选择与变量填写；券名自动生成；全部为到店活动，无适用范围字段。

## 发券流程

1. 选主类型：`打卡奖励` / `老师专属` / `最佳作品`
2. 选折扣类型：`赠送时长` / `折扣优惠`
3. 填变量：
   - 赠送时长：小时数 N + 有效期开始日 / 结束日（X–Y）
   - 折扣优惠：折扣 N（如 8 = 8 折）+ 有效期开始日 / 结束日（X–Y）
4. 预览自动券名后确认发放

## 数据（`user_coupons`）

| 字段 | 说明 |
|---|---|
| `category` | `checkin` \| `teacher` \| `best_work` |
| `benefitType` | `hours` \| `discount` |
| `benefitValue` | 小时数或折扣数（正数） |
| `name` | 自动生成快照，如 `打卡奖励 · 赠送 2 小时` |
| `validFrom` / `expireAt` | 有效期起止（日）：开始日 00:00:00.000 ~ 结束日 23:59:59.999 |
| `status` / `available` / … | 沿用既有生命周期字段 |

不再写入 `amount`、`scope`。不再接受手填 `name`、`expireDays`。

## 展示

右侧权益文案：`2小时` / `8折`（不再用 `¥`）。主标题用 `name`；有效期用 `YYYY-MM-DD 至 YYYY-MM-DD`。

## 范围

### In

- `adminIssueCoupon` 入参对齐
- 店主发券表单

- 单测与灌数脚本样例

### Out

- 历史旧券迁移

## 风险

- 库中若仍有旧 `amount`/`scope` 券，列表将无新结构权益文案（本轮不兼容兜底）
