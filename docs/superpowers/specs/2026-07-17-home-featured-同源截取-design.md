# 首页主推套餐 / 近期活动同源截取

## 目标

首页「开业主推套餐」「近期活动」与套餐页、活动页使用同一数据源，各截取列表前 3 条展示。

## 决策

- 数据源：`api.getPackages()` / `api.getActivities()`，失败时与列表页一致回退 seed。
- 套餐顺序：与套餐页相同的 `PACKAGE_ORDER` 排序后取前 3。
- 活动顺序：活动页默认「全部」列表顺序（云函数 `sortOrder` / seed 原序）取前 3，不限招募中。
- 展示：保留首页现有卡片字段与样式，仅替换数据组装逻辑。

## 非目标

- 不改首页视觉布局。
- 不改套餐页促销结算、活动页筛选交互。
