# 会员页：隐藏集章 + 智能亮点卡

## 目标

开发周期内暂时隐藏「我的集章」（代码保留可恢复），用一张智能亮点主卡顶替原视觉焦点，避免会员页变平。

## 决策

| 项 | 选择 |
|----|------|
| 集章 | `showStampCard: false` 隐藏，wxml/js/wxss/页面路由保留 |
| 亮点 | 单卡智能择优，不并排三模块摘要 |
| 优先级 | 进行中到店 > 行程 > 套餐 > 券 > 空态引导预约 |
| 列表 | 软去重：五项保留，当前主卡对应项的 badge/desc 与主卡对齐 |
| 空态 | 标题「去开一局」，点击进「我的行程」 |

## 主卡内容

| key | 标题 | 右侧 | 副文案要点 |
|-----|------|------|------------|
| seatSessions | 到店进行中 | 可空或耗时摘要 | 桌台/座位 + 已进行时长 |
| schedule | 我的行程 | N | 有行程条数 |
| packages | 我的套餐 | N 张语义 | 核销开台提示 |
| coupons | 优惠券 | N 张语义 | 到店核销 |
| schedule（空态） | 去开一局 | 空 | 预约开拼引导 |

## 数据

会员页并行拉取：ensureMember、优惠券、套餐、到店会话；行程条数 = 我的预约 + 我的活动报名（失败按 0）。

## 非目标

- 不删除集章页面与相关工具函数
- 不改动集章云逻辑
- 不做宫格快捷入口重构
